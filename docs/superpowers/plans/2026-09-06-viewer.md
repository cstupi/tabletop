# Developer Viewer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `viewer/` — a static Svelte page that draws a `sim/` recording top-down in inches, with a timeline and a log beside the board, plus a live feed that attaches to a running game server as a spectator with no team and manufactures the same frames in the browser.

**Architecture:** One input type: the recording schema `sim/Recording/Recording.cs` defines (`Recording`, `RecordedBoard`, `RecordedFrame`, …), whose frames carry whole state rather than deltas. The recording feed reads that file directly. The live feed reads `Tabletop.Protocol` off a WebSocket and *manufactures* the same `RecordedBoard` and `RecordedFrame[]` in TypeScript, so the renderer, the timeline and the panels have exactly one shape to draw and neither feed is privileged. Both TypeScript type sets are **generated from the C# by reflecting over `System.Text.Json`'s own contract metadata** and checked in, with a golden-file xUnit test as the drift guard. The board is a single 2D `<canvas>`.

**Tech Stack:** Node 24 (`~/.local/share/mise`), npm; `svelte` 5.57.0, `@sveltejs/vite-plugin-svelte` 7.3.0, `vite` 8.2.2, `vitest` 5.0.0, `typescript` 5.9.3, `svelte-check` 4.7.6. No SvelteKit, no three.js, no WebGL, no rendering library. `tests/Tabletop.Viewer.Tests` is a `net10.0` xUnit project.

**Spec:** `docs/superpowers/specs/2026-09-06-simulation-design.md` (primary — *The recording is the artifact*, *`viewer/` is a developer web app, separate from `web/`*, *Two feeds*, *Interactive debugging is a door, not a room*, *Testing*). Plans obeyed: `docs/superpowers/plans/2026-09-06-simulation.md` (**the recording schema, consumed verbatim**, and `RecordingJson.SchemaVersion`), `2026-09-05-contracts-and-local-dev.md` (`SocketMessage`, `EventPayload`, `StateChange`, `Ask`, `LegalSet`, `Projection`, `EventApplier`, `WireJson`, `ContentJson`), `2026-09-05-game-server-skeleton.md` (*Interfaces needed → Client shell plan*: the connect sequence, frame order and rejection cases), `2026-09-05-geometry.md` (the table frame, `Bodies.BaseOutline`, `WorldVolumes.WorldOutline`, `Point2.Rotate`), `2026-09-05-web-app.md` (**its Svelte, Vite and Vitest conventions and versions only** — `viewer/` shares no code and no build with `web/` and imports nothing from it), `2026-09-05-management-api.md` (only `POST /v1/auth/password` and `POST /v1/auth/session/refresh`, for the live feed's session JWT).

## Global Constraints

- **`viewer/` is a deliverable that ships to developers**, ruled by the project owner on 2026-09-06 (spec → *`sim/` is a fourth deliverable*): "Neither is in the client's export, neither is referenced by a server, and a release that omits both is complete."
- **The recording schema is consumed, never redefined.** `schemaVersion` is the integer `1` (`RecordingJson.SchemaVersion`); a file carrying any other value is refused rather than mis-drawn. Every field the viewer reads is a field the simulation plan's `Tabletop.Sim.Recording` records already declare. Fields the viewer needs and the schema does not have are listed under *Interfaces needed from other modules* and are **not** invented locally. Four were asked for on 2026-09-06 — `RecordedZone.Polygons`, `RecordedMarkerState`'s `Kind`/`Diameter`/`Label`, and `RecordedFrame`'s `Scores` and `Passed` — and the simulation plan applied all of them, so nothing in this plan reads a field through a cast or with a fallback any longer.
- **Frames are whole state, not deltas** (spec → *The recording is the artifact*): "Given frames, the viewer interpolates nothing and decides nothing; it draws what it is handed." A scrub to frame 300 reads frame 300 and nothing else. No accumulation, no interpolation, no tweening.
- **What is not built.** No command, no Ask answer, no editing, no pausing a simulation, no interactive control of any kind, and no auth beyond a spectator session JWT. The viewer sends exactly one frame ever — `Connect` — and after that it only receives. The seam is left, per spec → *Interactive debugging is a door, not a room*: `Feed` has a `control` member that is `null` in both implementations, and the open Ask is displayed at every frame. Building on that seam "makes the viewer a second thin client, which is a larger surface than a renderer" and is out of scope.
- **Top-down and schematic. No 3D, no mesh, ever** (spec → *`viewer/` is a developer web app*): "a model is its base and its facing." `z` is read only to label a model that is standing on something.
- One world unit = one inch. The table frame is the corner frame: origin at a table corner, `0 ≤ x ≤ width`, `0 ≤ y ≤ length`, `z` up; yaw 0 faces `+y` and positive yaw turns counter-clockwise seen from above (contracts plan → *Interfaces → Produces → `Tabletop.Geometry`*; geometry plan → *Coordinate frame*). Canvas `y` grows downward, so the view flips `y` once, in `transform.ts`, and nowhere else.
- **The renderer has one input shape.** `RecordedBoard` + `RecordedFrame`. The live feed's job is to produce them; nothing downstream of `Feed` knows which feed it is attached to.
- **The TypeScript protocol types are generated, not written.** Spec → *Two feeds*: "the TypeScript types are generated from the C# records rather than hand-written, and the applier is checked against the C# one by replaying a recording through both and comparing projections. A hand-maintained second applier was rejected." Generated output is checked in; `tests/Tabletop.Viewer.Tests` regenerates and diffs, so `dotnet test` fails on drift and `npm run build` needs no .NET SDK. The generated surface is only what the live feed reads — no `Command`, no `Edit`, no `Presence`, no `Ping`.
- **The applier is checked against the C# one by whole-frame comparison.** The recording's frames *are* the C# `EventApplier`'s output, canonicalised; so replaying the same event log through the TypeScript applier must reproduce them field for field. The comparison normalises collection order (sort by id, sort string arrays) on both sides and deep-compares everything else, including `line`.
- **Nothing is imported from `web/`** and nothing under `viewer/` is referenced by `Tabletop.sln`. `viewer/` has its own `package.json` and its own lockfile.
- TypeScript strict, `noUncheckedIndexedAccess`. Vitest covers every module under `src/lib/**` with logic — the recording reader, the frame-to-geometry projection, the timeline reducer, the Ask description, and the ported applier (spec → *Testing*). Svelte components are checked by looking at them.
- Ports: viewer dev server `5174` (`web/` owns `5173`), proxying `/v1` to management on `5100`; the game server socket is `ws://localhost:5200/ws`.
- Commit after every task, one imperative line, with the `Co-Authored-By` and `Claude-Session` trailers the repo uses.
- The last task edits `CLAUDE.md` and `docs/architecture.md`. **The simulation plan (`2026-09-06-simulation.md`, Task 11) edits both files first and already writes `viewer/`'s one line into each**; this plan's Task 12 is written against the text as that task leaves it, and says so at every edit.

**Files:**
- Create: `tests/Tabletop.Viewer.Tests/Tabletop.Viewer.Tests.csproj`, `tests/Tabletop.Viewer.Tests/RepoPaths.cs`, `tests/Tabletop.Viewer.Tests/TypeScriptEmitter.cs`, `tests/Tabletop.Viewer.Tests/GeneratedTypesTests.cs`

**Interfaces:**
- Consumes: `Tabletop.Sim.Recording.Recording` and `RecordingJson.Options`, `RecordingJson.SchemaVersion` (simulation plan Task 5); `Tabletop.Protocol.WireJson.Options`, `SocketMessage`, `Connect`, `Welcome`, `GameInfoMessage`, `BoardMessage`, `EventsMessage`, `Refused`, `Rejected` (contracts plan Task 12).
- Produces: `sealed record EmitRequest(string Module, JsonSerializerOptions Options, IReadOnlyList<Type> Roots, IReadOnlyDictionary<Type, IReadOnlyList<Type>> PrunedUnions, IReadOnlyDictionary<Type, string> Rename)`; `static class TypeScriptEmitter` with `string Emit(EmitRequest)`; `static class RepoPaths` with `string Root`, `string Viewer`, `string Fixtures`; the two generated `.ts` modules, each exporting one TypeScript declaration per reachable JSON contract.
- Produces for `viewer/`: from `recording.generated.ts` — `Point2`, `Recording`, `RecordingMeta`, `RecordedTeam`, `RecordedBoard`, `RecordedTerrain`, `RecordedVolume`, `RecordedMarker`, `RecordedZone`, `RecordedModel`, `RecordedFrame`, `RecordedModelState`, `RecordedUnitState`, `RecordedMarkerState`, `RecordedAsk`, `RecordedAskOption`, `RecordedRoll`, `RecordedModifier`, and `SCHEMA_VERSION`. From `wire.generated.ts` — `ServerMessage` plus every type reachable from the seven roots.
- `Point2` is `Tabletop.Geometry.Point2`, reachable only through `RecordedZone.Polygons`. It is the one Geometry type the recording schema names, and it emits as `{ readonly x: number; readonly y: number }`, which is structurally `board/transform.ts`'s `Point`.

**Field order is part of the generated file.** The emitter walks `JsonTypeInfo.Properties` in order, so each interface's members come out in the C# record's positional order and the golden file records it. `RecordedMarkerState` is `Id, Kind, Diameter, Label, X, Y, Z, Yaw` — the definition first, then the placement — and Step 1's test pins that line for line, because a reordered record is a silent one-line diff in the golden file rather than a compile error anywhere. Declarations themselves are sorted by name, not by discovery, so `Point2` is the first declaration in `recording.generated.ts`.

Spec: spec → *Two feeds* — "the TypeScript types are generated from the C# records rather than hand-written"; *Still open* — "Whether generating TypeScript types from the C# records is worth a build step, or whether a checked-in generated file is enough" (this task answers it: checked in, guarded by a test). Simulation plan → *Interfaces needed from other modules*, item 6: "It should generate its TypeScript types from these C# records … rather than hand-writing them."

**Why `JsonTypeInfo` and not reflection over the records.** The emitter asks `System.Text.Json` what the JSON looks like — `JsonTypeInfo.Properties[i].Name` is the wire name, so `[JsonPropertyName("schemaVersion")]` and the camelCase policy are honoured without being reimplemented; `JsonPolymorphismOptions.DerivedTypes` gives the discriminator property and every `kind` string; and an enum's wire spelling is obtained by serialising the value rather than by guessing between `snake_case` and `kebab-case`. A reflection-over-properties emitter would be a second implementation of the JSON conventions, which is the drift this whole approach exists to remove.

```csharp
// tests/Tabletop.Viewer.Tests/RepoPaths.cs
namespace Tabletop.Viewer.Tests;

/// <summary>The repo root, found by walking up from the test assembly until Tabletop.sln appears.</summary>
public static class RepoPaths
{
    public static string Root { get; } = Find();
    public static string Viewer => Path.Combine(Root, "viewer");
    public static string Generated => Path.Combine(Viewer, "src", "lib", "protocol");
    public static string Fixtures => Path.Combine(Viewer, "tests", "fixtures");

    private static string Find()
    {
        var dir = new DirectoryInfo(AppContext.BaseDirectory);
        while (dir is not null && !File.Exists(Path.Combine(dir.FullName, "Tabletop.sln"))) dir = dir.Parent;
        return dir?.FullName ?? throw new DirectoryNotFoundException("Tabletop.sln not found above the test assembly.");
    }
}
```

```csharp
// tests/Tabletop.Viewer.Tests/GeneratedTypesTests.cs
using Tabletop.Protocol;
using Tabletop.Sim.Recording;

namespace Tabletop.Viewer.Tests;

/// <summary>
/// The drift guard. `TABLETOP_WRITE_GENERATED=1 dotnet test tests/Tabletop.Viewer.Tests` rewrites the two
/// checked-in modules; every other run asserts they are byte for byte what the C# would emit today.
/// </summary>
public class GeneratedTypesTests
{
    public static EmitRequest RecordingModule => new(
        "recording.generated.ts", RecordingJson.Options, [typeof(Recording)],
        new Dictionary<Type, IReadOnlyList<Type>>(), new Dictionary<Type, string>());

    public static EmitRequest WireModule => new(
        "wire.generated.ts", WireJson.Options,
        [typeof(SocketMessage)],
        // Only what the live feed reads. No Command, no Edit, no Presence, no Ping (spec → Two feeds:
        // "Keep the generated surface as small as the live feed actually needs").
        new Dictionary<Type, IReadOnlyList<Type>>
        {
            [typeof(SocketMessage)] =
            [
                typeof(Connect), typeof(Welcome), typeof(GameInfoMessage), typeof(BoardMessage),
                typeof(EventsMessage), typeof(Refused), typeof(Rejected),
            ],
        },
        new Dictionary<Type, string>());

    public static TheoryData<string> Modules() => new("recording.generated.ts", "wire.generated.ts");

    static EmitRequest RequestFor(string module) => module == "recording.generated.ts" ? RecordingModule : WireModule;

    [Theory]
    [MemberData(nameof(Modules))]
    public void The_checked_in_module_is_what_the_csharp_emits_today(string module)
    {
        var emitted = TypeScriptEmitter.Emit(RequestFor(module));
        var path = Path.Combine(RepoPaths.Generated, module);
        if (Environment.GetEnvironmentVariable("TABLETOP_WRITE_GENERATED") == "1")
        {
            Directory.CreateDirectory(RepoPaths.Generated);
            File.WriteAllText(path, emitted);
        }
        Assert.True(File.Exists(path), $"{path} is missing; run TABLETOP_WRITE_GENERATED=1 dotnet test tests/Tabletop.Viewer.Tests");
        Assert.Equal(emitted, File.ReadAllText(path));
    }

    [Fact]
    public void The_recording_module_carries_the_schema_version_and_its_own_property_names()
    {
        var ts = TypeScriptEmitter.Emit(RecordingModule);
        Assert.Contains($"export const SCHEMA_VERSION = {RecordingJson.SchemaVersion};", ts);
```

```csharp
using System.Collections;
using System.Reflection;
using System.Text;
using System.Text.Json;
using System.Text.Json.Serialization.Metadata;

namespace Tabletop.Viewer.Tests;

/// <param name="PrunedUnions">Unions to emit with fewer members than the C# declares — the live feed's subset.</param>
/// <param name="Rename">The escape hatch for two C# types with one name; empty until one collides.</param>
public sealed record EmitRequest(
    string Module,
    JsonSerializerOptions Options,
    IReadOnlyList<Type> Roots,
    IReadOnlyDictionary<Type, IReadOnlyList<Type>> PrunedUnions,
    IReadOnlyDictionary<Type, string> Rename);

/// <summary>
/// Emits TypeScript from System.Text.Json's own contracts, so no JSON convention is reimplemented here:
/// property names come from JsonPropertyInfo.Name, unions and their `kind` strings from
/// JsonPolymorphismOptions, and an enum's spelling from serialising the value. A computed C# property that
/// System.Text.Json includes appears in the output, because the output must describe the bytes, not the records.
/// </summary>
public static class TypeScriptEmitter
{
    public static string Emit(EmitRequest request)
    {
        var declarations = new SortedDictionary<string, string>(StringComparer.Ordinal);
        var names = new Dictionary<Type, string>();
        var discriminators = new Dictionary<Type, string>();
        var queue = new Queue<Type>(request.Roots);
        var seen = new HashSet<Type>(request.Roots);

        // First pass: names and discriminators, so a declaration can refer to a type queued after it.
        while (queue.Count > 0)
        {
            var type = queue.Dequeue();
            names[type] = Name(request, type);
            foreach (var next in Referenced(request, type, discriminators))
                if (seen.Add(next)) queue.Enqueue(next);
        }

        foreach (var type in names.Keys.ToList())
            declarations[names[type]] = Declare(request, type, names, discriminators);

        var body = new StringBuilder();
        body.Append("// GENERATED by tests/Tabletop.Viewer.Tests/TypeScriptEmitter.cs. Do not edit.\n");
        body.Append("// Regenerate: TABLETOP_WRITE_GENERATED=1 dotnet test tests/Tabletop.Viewer.Tests\n");
        if (request.Module.StartsWith("recording", StringComparison.Ordinal))
            body.Append($"\nexport const SCHEMA_VERSION = {Tabletop.Sim.Recording.RecordingJson.SchemaVersion};\n");
        foreach (var (_, text) in declarations) body.Append('\n').Append(text);
        return body.ToString();
    }

    private static string Name(EmitRequest r, Type t) => r.Rename.TryGetValue(t, out var n) ? n : t.Name;

    /// <summary>Types this one's declaration will mention, and (for a union) each member's `kind`.</summary>
    private static IEnumerable<Type> Referenced(EmitRequest r, Type type, Dictionary<Type, string> discriminators)
    {
        if (type.IsEnum) yield break;
        var info = r.Options.GetTypeInfo(type);
        if (info.PolymorphismOptions is { } poly)
        {
            foreach (var derived in Members(r, type, poly))
            {
                var kind = poly.DerivedTypes.Single(d => d.DerivedType == derived).TypeDiscriminator?.ToString()
                    ?? throw new InvalidOperationException($"{derived.Name} has no string discriminator.");
                if (discriminators.TryGetValue(derived, out var already) && already != kind)
                    throw new InvalidOperationException($"{derived.Name} is '{already}' in one union and '{kind}' in another.");
                discriminators[derived] = kind;
                yield return derived;
            }
            yield break;
        }
        foreach (var property in info.Properties)
            foreach (var referenced in Leaves(property.PropertyType))
                yield return referenced;
    }

    private static IReadOnlyList<Type> Members(EmitRequest r, Type union, JsonPolymorphismOptions poly) =>
        r.PrunedUnions.TryGetValue(union, out var subset) ? subset : poly.DerivedTypes.Select(d => d.DerivedType).ToList();

    /// <summary>Every non-primitive type inside a property type: unwraps Nullable, arrays, lists and dictionaries.</summary>
    private static IEnumerable<Type> Leaves(Type type)
    {
        var t = Nullable.GetUnderlyingType(type) ?? type;
        if (Element(t) is { } element) { foreach (var leaf in Leaves(element)) yield return leaf; yield break; }
        if (Primitive(t) is not null) yield break;
        yield return t;
    }

    private static Type? Element(Type t)
    {
        if (t == typeof(string) || !t.IsGenericType) return t.IsArray ? t.GetElementType() : null;
        var args = t.GetGenericArguments();
        var open = t.GetGenericTypeDefinition();
        if (open == typeof(IReadOnlyDictionary<,>) || open == typeof(Dictionary<,>)) return args[1];
        return typeof(IEnumerable).IsAssignableFrom(t) ? args[0] : null;
    }

    private static string? Primitive(Type t) => t switch
    {
        _ when t == typeof(string) || t == typeof(Guid) || t == typeof(DateTimeOffset) || t == typeof(DateTime) => "string",
        _ when t == typeof(bool) => "boolean",
        _ when t == typeof(int) || t == typeof(long) || t == typeof(ulong) || t == typeof(uint)
            || t == typeof(short) || t == typeof(double) || t == typeof(float) || t == typeof(decimal) => "number",
        _ => null,
    };

    private static string Declare(EmitRequest r, Type type, Dictionary<Type, string> names, Dictionary<Type, string> kinds)
    {
        var name = names[type];
        if (type.IsEnum) return DeclareEnum(r, type, name);

        var info = r.Options.GetTypeInfo(type);
        if (info.PolymorphismOptions is { } poly)
        {
            var members = string.Join(" | ", Members(r, type, poly).Select(m => names[m]));
            return $"export type {name} = {members};\n";
        }

        var text = new StringBuilder($"export interface {name} {{\n");
        if (kinds.TryGetValue(type, out var kind)) text.Append($"  readonly kind: '{kind}';\n");
        var nullability = new NullabilityInfoContext();
        foreach (var property in info.Properties)
        {
            var optional = IsOptional(property, nullability);
            text.Append($"  readonly {property.Name}{(optional ? "?" : "")}: {Reference(r, property.PropertyType, names)};\n");
        }
        return text.Append("}\n").ToString();
    }

    /// <summary>Serialise every member so the emitter never guesses between snake_case and kebab-case.</summary>
    private static string DeclareEnum(EmitRequest r, Type type, string name)
    {
        if (type.GetCustomAttribute<FlagsAttribute>() is not null)
            return $"/** [Flags] {type.Name}: a comma-joined list of set names, or 'none'. */\nexport type {name} = string;\n";
        var literals = Enum.GetValues(type).Cast<object>()
            .Select(v => JsonSerializer.Serialize(v, type, r.Options).Trim('"'))
            .Select(s => $"'{s}'");
        return $"export type {name} = {string.Join(" | ", literals)};\n";
    }

    private static string Reference(EmitRequest r, Type type, Dictionary<Type, string> names)
    {
        var t = Nullable.GetUnderlyingType(type) ?? type;
        if (Primitive(t) is { } primitive) return primitive;
        if (t.IsGenericType && (t.GetGenericTypeDefinition() == typeof(IReadOnlyDictionary<,>) || t.GetGenericTypeDefinition() == typeof(Dictionary<,>)))
            return $"{{ readonly [key: string]: {Reference(r, t.GetGenericArguments()[1], names)} }}";
        if (Element(t) is { } element) return $"readonly {Reference(r, element, names)}[]";
        return names.TryGetValue(t, out var name) ? name
            : throw new InvalidOperationException($"{t.FullName} was referenced but never queued.");
    }

    private static bool IsOptional(JsonPropertyInfo property, NullabilityInfoContext context)
    {
        if (Nullable.GetUnderlyingType(property.PropertyType) is not null) return true;
        return property.AttributeProvider switch
        {
            PropertyInfo p => context.Create(p).ReadState is NullabilityState.Nullable,
            FieldInfo f => context.Create(f).ReadState is NullabilityState.Nullable,
            _ => false,
        };
    }
}
```

```ts
// viewer/src/lib/recording/read.ts
import { SCHEMA_VERSION, type Recording } from '../protocol/recording.generated';

/** A file this viewer will not draw. The fix is to re-run sim/, because a recording is derived. */
export class RecordingError extends Error {}

function object(value: unknown, what: string): Record<string, unknown> {
  if (typeof value !== 'object' || value === null || Array.isArray(value))
    throw new RecordingError(`${what} is not an object`);
  return value as Record<string, unknown>;
}

function array(value: unknown, what: string): readonly unknown[] {
  if (!Array.isArray(value)) throw new RecordingError(`${what} is not an array`);
  return value;
}

export function readRecording(value: unknown): Recording {
  const root = object(value, 'the recording');
  if (root.schemaVersion !== SCHEMA_VERSION)
    throw new RecordingError(
      `schemaVersion ${root.schemaVersion} is not supported; this viewer reads ${SCHEMA_VERSION}. ` +
        `Re-run sim/ to get a current recording.`,
    );

  const meta = object(root.meta, 'meta');
  array(meta.teams, 'meta.teams');
  const board = object(root.board, 'board');
  const models = array(board.models, 'board.models');
  array(board.terrain, 'board.terrain');
  array(board.markers, 'board.markers');
  array(board.zones, 'board.zones');
  if (typeof board.width !== 'number' || typeof board.length !== 'number')
    throw new RecordingError('board.width and board.length must be numbers');

  const known = new Set(models.map((m) => object(m, 'a board model').id as string));
  const frames = array(root.frames, 'frames');
  frames.forEach((raw, i) => {
    const frame = object(raw, `frame ${i}`);
    if (frame.index !== i) throw new RecordingError(`frame ${i} carries index ${frame.index}`);
    if (typeof frame.seq !== 'number') throw new RecordingError(`frame ${i} has no seq`);
    if (typeof frame.line !== 'string') throw new RecordingError(`frame ${i} has no line`);
    array(frame.units, `frame ${i}.units`);
    array(frame.markers, `frame ${i}.markers`);
    array(frame.openAsks, `frame ${i}.openAsks`);
    array(frame.rolls, `frame ${i}.rolls`);
    for (const m of array(frame.models, `frame ${i}.models`)) {
      const id = object(m, `a model in frame ${i}`).id as string;
      if (!known.has(id)) throw new RecordingError(`frame ${i} names model ${id}, which board.models does not define`);
    }
  });

  return value as Recording;
}

export function parseRecording(text: string): Recording {
  let parsed: unknown;
  try {
    parsed = JSON.parse(text);
  } catch (cause) {
    throw new RecordingError(`not JSON: ${(cause as Error).message}`);
  }
  return readRecording(parsed);
}

export function teamOrdinals(r: Recording): ReadonlyMap<string, number> {
  return new Map(r.meta.teams.map((t) => [t.id, t.ordinal]));
}

export function teamNames(r: Recording): ReadonlyMap<string, string> {
  return new Map(r.meta.teams.map((t) => [t.id, t.name]));
}
```

```ts
// viewer/src/lib/recording/source.ts
import type { Recording } from '../protocol/recording.generated';
import { RecordingError, parseRecording } from './read';

export type RecordingSource = { readonly label: string; readonly recording: Recording };

export async function fromFile(file: File): Promise<RecordingSource> {
  return { label: file.name, recording: parseRecording(await file.text()) };
}

export async function fromUrl(url: string): Promise<RecordingSource> {
  const response = await fetch(url);
  if (!response.ok) throw new RecordingError(`${url} answered ${response.status} ${response.statusText}`);
  return { label: url, recording: parseRecording(await response.text()) };
}

/** `?recording=<url>` — the whole of the viewer's routing (Task 1: no router). */
export function recordingUrlFrom(search: string): string | null {
  return new URLSearchParams(search).get('recording');
}
```

**Deployment zones.** `RecordedZone` carries `shape` (a shape id such as `frontline/1`), `teamOrdinal` and, since 2026-09-06, `polygons` — an array of rings of `{x, y}` already resolved by `Tabletop.Geometry.ZoneStyles.Resolve` and already in the corner frame, so the viewer converts nothing and resolves nothing. // viewer/src/lib/board/transform.ts
```ts
export type Point = { readonly x: number; readonly y: number };
export type Table = { readonly width: number; readonly length: number };
export type Viewport = { readonly width: number; readonly height: number };
/** Pixels per inch, and the screen position of the table's top-left corner (x = 0, y = length). */
export type View = { readonly scale: number; readonly panX: number; readonly panY: number };

export const MARGIN = 12;

export function fit(table: Table, viewport: Viewport): View {
  const usableWidth = Math.max(1, viewport.width - 2 * MARGIN);
  const usableHeight = Math.max(1, viewport.height - 2 * MARGIN);
  const scale = Math.min(usableWidth / table.width, usableHeight / table.length);
  return {
    scale,
    panX: (viewport.width - table.width * scale) / 2,
    panY: (viewport.height - table.length * scale) / 2,
  };
}

/** The only place y is flipped: the table's y grows away from the near edge, the canvas's grows downward. */
export function toScreen(view: View, table: Table, p: Point): Point {
  return { x: view.panX + p.x * view.scale, y: view.panY + (table.length - p.y) * view.scale };
}

export function toTable(view: View, table: Table, p: Point): Point {
  return { x: (p.x - view.panX) / view.scale, y: table.length - (p.y - view.panY) / view.scale };
}

export function zoomAt(view: View, table: Table, screen: Point, factor: number): View {
  const scale = Math.min(400, Math.max(0.25, view.scale * factor));
  const anchor = toTable(view, table, screen);
  return {
    scale,
    panX: screen.x - anchor.x * scale,
    panY: screen.y - (table.length - anchor.y) * scale,
  };
}

export function panBy(view: View, dx: number, dy: number): View {
  return { scale: view.scale, panX: view.panX + dx, panY: view.panY + dy };
}

/** Inches between grid lines: the smallest of 1, 3, 6, 12 that keeps lines at least 12 px apart. */
export function gridStep(view: View): number {
  for (const step of [1, 3, 6, 12]) if (step * view.scale >= 12) return step;
  return 12;
}

/** Tabletop.Geometry.Point2.Rotate: about the origin; yaw 0 faces +y, positive yaw turns counter-clockwise. */
export function rotate(p: Point, yawDegrees: number): Point {
  const radians = (yawDegrees * Math.PI) / 180;
  const s = Math.sin(radians);
  const c = Math.cos(radians);
  return { x: p.x * c - p.y * s, y: p.x * s + p.y * c };
}
```

```ts
// viewer/src/lib/board/frame.ts
import type {
  RecordedBoard, RecordedFrame, RecordedModel, RecordedModelState, RecordedTerrain, RecordedVolume,
} from '../protocol/recording.generated';
import { type Point, rotate } from './transform';

export type Shape =
  | { readonly kind: 'circle'; readonly centre: Point; readonly radius: number }
  | { readonly kind: 'polygon'; readonly points: readonly Point[] };

/** Tabletop.Geometry.Bodies.OvalVertices. */
export const OVAL_VERTICES = 64;

export type ModelShape = {
  readonly id: string; readonly unitId: string; readonly unitName: string; readonly label: string;
  readonly teamId: string; readonly teamOrdinal: number;
  readonly centre: Point; readonly shape: Shape; readonly facing: readonly [Point, Point] | null;
  readonly wounds: number; readonly spellTokens: number; readonly conditions: readonly string[];
  readonly elevated: boolean;
};
export type TerrainShape = {
  readonly id: string; readonly volumeId: string; readonly label: string;
  readonly kind: string; readonly declarations: readonly string[];
  readonly shape: Shape; readonly bottom: number; readonly top: number; readonly notes?: string;
};
export type MarkerShape = {
  readonly id: string; readonly kind: string; readonly label: string;
  readonly centre: Point; readonly radius: number;
};
export type ZoneShape = {
  readonly id: string; readonly shape: string; readonly teamOrdinal: number; readonly polygons: readonly Shape[];
};
export type OffTable = {
  readonly id: string; readonly label: string; readonly teamOrdinal: number;
  readonly where: string; readonly containerLabel?: string;
};
export type Scene = {
  readonly table: { readonly width: number; readonly length: number };
  readonly terrain: readonly TerrainShape[];
  readonly zones: readonly ZoneShape[];
  readonly markers: readonly MarkerShape[];
  readonly models: readonly ModelShape[];
  readonly offTable: readonly OffTable[];
};

/** Tabletop.Geometry.Bodies.BaseOutline, ported: circle, square and a 64-gon oval, all placed by yaw. */
export function baseOutline(model: RecordedModel, centre: Point, yaw: number): Shape {
  const place = (local: readonly Point[]): Shape => ({
    kind: 'polygon',
    points: local.map((p) => {
      const turned = rotate(p, yaw);
      return { x: turned.x + centre.x, y: turned.y + centre.y };
    }),
  });
  if (model.baseShape === 'circle') return { kind: 'circle', centre, radius: model.baseA / 2 };
  if (model.baseShape === 'square') {
    const h = model.baseA / 2;
    return place([{ x: -h, y: -h }, { x: h, y: -h }, { x: h, y: h }, { x: -h, y: h }]);
  }
  return place(
    Array.from({ length: OVAL_VERTICES }, (_, i) => {
      const t = (2 * Math.PI * i) / OVAL_VERTICES;
      return { x: (model.baseB / 2) * Math.cos(t), y: (model.baseA / 2) * Math.sin(t) };
    }),
  );
}

/** Tabletop.Geometry.WorldVolumes.WorldOutline, ported: the piece's position, yaw and uniform scale applied. */
export function volumeOutline(terrain: RecordedTerrain, volume: RecordedVolume): Shape {
  const s = terrain.scale;
  const offset = rotate({ x: volume.offsetX * s, y: volume.offsetY * s }, terrain.yaw);
  const centre = { x: terrain.x + offset.x, y: terrain.y + offset.y };
  if (volume.footprint === 'circle') return { kind: 'circle', centre, radius: volume.a * s };
  const hw = (volume.a * s) / 2;
  const hl = (volume.b * s) / 2;
  const yaw = terrain.yaw + volume.yaw;
  return {
    kind: 'polygon',
    points: [{ x: -hw, y: -hl }, { x: hw, y: -hl }, { x: hw, y: hl }, { x: -hw, y: hl }].map((p) => {
      const turned = rotate(p, yaw);
      return { x: turned.x + centre.x, y: turned.y + centre.y };
    }),
  };
}

export function sceneOf(board: RecordedBoard, frame: RecordedFrame): Scene {
  const definitions = new Map(board.models.map((m) => [m.id, m]));
  const models: ModelShape[] = [];
  const offTable: OffTable[] = [];

  for (const state of frame.models) {
    const definition = definitions.get(state.id);
    if (definition === undefined) continue;                    // read.ts already refused this file
    if (state.where !== 'table' || state.x === undefined || state.y === undefined) {
      offTable.push({
        id: state.id, label: definition.name, teamOrdinal: definition.teamOrdinal, where: state.where,
        ...(state.containerId !== undefined
          ? { containerLabel: definitions.get(state.containerId)?.name ?? state.containerId }
          : {}),
      });
      continue;
    }
    const centre = { x: state.x, y: state.y };
    const yaw = state.yaw ?? 0;
    const reach = rotate({ x: 0, y: definition.baseA / 2 }, yaw);
    models.push({
      id: state.id, unitId: definition.unitId, unitName: definition.unitName, label: definition.name,
      teamId: definition.teamId, teamOrdinal: definition.teamOrdinal,
      centre, shape: baseOutline(definition, centre, yaw),
      facing: [centre, { x: centre.x + reach.x, y: centre.y + reach.y }],
      wounds: state.wounds, spellTokens: state.spellTokens, conditions: state.conditions,
      elevated: (state.z ?? 0) > 0.01,
    });
  }

  const terrain: TerrainShape[] = board.terrain.flatMap((piece) =>
    piece.volumes.map((volume) => ({
      id: piece.id, volumeId: volume.id, label: piece.mesh, kind: volume.kind,
      declarations: volume.declarations, shape: volumeOutline(piece, volume),
      bottom: piece.z + volume.bottom * piece.scale, top: piece.z + volume.top * piece.scale,
      ...(volume.notes !== undefined ? { notes: volume.notes } : {}),
    })),
  );

  // A marker state carries its own definition, so board.markers is never consulted here: a marker
  // dropped during play is in no board block, and where both name one they agree.
  const markers: MarkerShape[] = frame.markers.map((state) => ({
    id: state.id, kind: state.kind, label: state.label ?? state.id,
    centre: { x: state.x, y: state.y }, radius: state.diameter / 2,
  }));

  // Rings are already resolved and already in the corner frame; an empty list draws no outline.
  const zones: ZoneShape[] = board.zones.map((zone) => ({
    id: zone.id, shape: zone.shape, teamOrdinal: zone.teamOrdinal,
    polygons: zone.polygons.map((points) => ({ kind: 'polygon', points }) as Shape),
  }));

  return { table: { width: board.width, length: board.length }, terrain, zones, markers, models, offTable };
}
```

`sceneOf` reads no optional or casted field: every field it touches — `zone.polygons`, `marker.kind`, `marker.diameter`, `marker.label` — is declared by `recording.generated.ts`, so a schema change is a type error here rather than a silent `undefined`.

- Produces (`draw.ts`): `type DrawOptions = { readonly selected?: string; readonly hovered?: string; readonly showGrid: boolean; readonly showZones: boolean; readonly showLabels: boolean }`; `function draw(ctx: CanvasRenderingContext2D, scene: Scene, view: View, viewport: Viewport, options: DrawOptions): void`.
- Produces (`Board.svelte`): props `{ scene: Scene, selected: string | null, onPick: (hit: Hit | null) => void, showGrid: boolean, showZones: boolean, showLabels: boolean }`; owns the `<canvas>`, its `ResizeObserver`, the device-pixel-ratio scaling, wheel zoom, drag pan, and a `Reset view` button.

**Canvas, not SVG.** Frames carry whole state, so a scrub to any frame invalidates every model, every marker and every position on the board at once — there is no partial update for a retained-mode tree to exploit. At a few hundred models the SVG document is roughly 300 base nodes plus 300 facing ticks plus terrain outlines plus 120 grid lines, and moving the timeline one step rewrites an attribute on every one of them, so the browser pays style recalculation and layout for the whole tree per frame; dragging the scrubber does that at pointer rate. A single `<canvas>` pays one `clearRect` and about 800 path operations per frame, which is well inside a 16 ms budget and does not grow a DOM. The two things SVG would have given away free — hit testing and text layout — are cheap here because a base is a circle, a square or a convex 64-gon in table space, so `pickAt` is a point test in inches with no screen-space maths, and the only text is a short label drawn with `fillText`. WebGL and any drawing library are refused outright: the workload does not need them and the spec's whole point about the viewer is that it is schematic (spec → *`viewer/` is a developer web app*: "Nothing is rendered in 3D and no mesh is ever loaded").

```ts
import type { Scene, Shape } from './frame';
import type { Point } from './transform';

export type Hit =
  | { readonly kind: 'model'; readonly id: string }
  | { readonly kind: 'terrain'; readonly id: string; readonly volumeId: string };

/** Boundary inclusive, any vertex order, concave allowed — Tabletop.Geometry.Polygon.Contains's contract. */
export function contains(shape: Shape, p: Point): boolean {
  if (shape.kind === 'circle') {
    const dx = p.x - shape.centre.x;
    const dy = p.y - shape.centre.y;
    return dx * dx + dy * dy <= shape.radius * shape.radius;
  }
  const points = shape.points;
  let inside = false;
  for (let i = 0, j = points.length - 1; i < points.length; j = i++) {
    const a = points[i]!;
    const b = points[j]!;
    const cross = (b.x - a.x) * (p.y - a.y) - (b.y - a.y) * (p.x - a.x);
    const along = (p.x - a.x) * (b.x - a.x) + (p.y - a.y) * (b.y - a.y);
    const lengthSquared = (b.x - a.x) ** 2 + (b.y - a.y) ** 2;
    if (Math.abs(cross) <= 1e-9 && along >= -1e-9 && along <= lengthSquared + 1e-9) return true;   // on an edge
    if (a.y > p.y !== b.y > p.y && p.x < a.x + ((p.y - a.y) / (b.y - a.y)) * (b.x - a.x)) inside = !inside;
  }
  return inside;
}

/** Models first, last drawn wins, then terrain. Table inches in, never screen pixels. */
export function pickAt(scene: Scene, p: Point): Hit | null {
  for (let i = scene.models.length - 1; i >= 0; i--) {
    const model = scene.models[i]!;
    if (contains(model.shape, p)) return { kind: 'model', id: model.id };
  }
  for (let i = scene.terrain.length - 1; i >= 0; i--) {
    const piece = scene.terrain[i]!;
    if (contains(piece.shape, p)) return { kind: 'terrain', id: piece.id, volumeId: piece.volumeId };
  }
  return null;
}
```

```ts
// viewer/src/lib/board/draw.ts
import type { Scene, Shape } from './frame';
import { markerColour, teamColour, terrainStroke } from './palette';
import { type View, type Viewport, gridStep, toScreen } from './transform';

export type DrawOptions = {
  readonly selected?: string | undefined;
  readonly hovered?: string | undefined;
  readonly showGrid: boolean;
  readonly showZones: boolean;
  readonly showLabels: boolean;
};

export function draw(
  ctx: CanvasRenderingContext2D, scene: Scene, view: View, viewport: Viewport, options: DrawOptions,
): void {
  const table = scene.table;
  const at = (x: number, y: number) => toScreen(view, table, { x, y });

  ctx.save();
  ctx.clearRect(0, 0, viewport.width, viewport.height);

  // The slab.
  const origin = at(0, table.length);
  ctx.fillStyle = '#1b1e24';
  ctx.fillRect(origin.x, origin.y, table.width * view.scale, table.length * view.scale);

  if (options.showGrid) {
    const step = gridStep(view);
    ctx.lineWidth = 1;
    for (let x = 0; x <= table.width + 1e-9; x += step) {
      ctx.strokeStyle = x % 12 === 0 ? '#39404c' : '#252a32';
      line(ctx, at(x, 0), at(x, table.length));
    }
    for (let y = 0; y <= table.length + 1e-9; y += step) {
      ctx.strokeStyle = y % 12 === 0 ? '#39404c' : '#252a32';
      line(ctx, at(0, y), at(table.width, y));
    }
  }

  if (options.showZones) {
    ctx.setLineDash([6, 4]);
    for (const zone of scene.zones) {
      ctx.strokeStyle = teamColour(zone.teamOrdinal);
      ctx.lineWidth = 1.5;
      for (const polygon of zone.polygons) path(ctx, polygon, view, table), ctx.stroke();
    }
    ctx.setLineDash([]);
  }

  for (const piece of scene.terrain) {
    ctx.strokeStyle = terrainStroke(piece.declarations);
    ctx.lineWidth = piece.kind === 'solid' ? 2 : 1;
    if (piece.kind === 'area') ctx.setLineDash([3, 3]);
    path(ctx, piece.shape, view, table);
    ctx.stroke();
    ctx.setLineDash([]);
    if (options.showLabels) {
      const centre = shapeCentre(piece.shape);
      const p = at(centre.x, centre.y);
      ctx.fillStyle = terrainStroke(piece.declarations);
      ctx.font = '10px ui-monospace, monospace';
      ctx.textAlign = 'center';
      ctx.fillText(piece.label, p.x, p.y - 4);
      ctx.fillText(piece.declarations.join(' · ') || piece.kind, p.x, p.y + 8);
    }
  }

  for (const marker of scene.markers) {
    const p = at(marker.centre.x, marker.centre.y);
    ctx.strokeStyle = markerColour(marker.kind);
    ctx.lineWidth = 1.5;
    ctx.beginPath();
    ctx.arc(p.x, p.y, Math.max(3, marker.radius * view.scale), 0, 2 * Math.PI);
    ctx.stroke();
    if (options.showLabels) {
      ctx.fillStyle = markerColour(marker.kind);
      ctx.font = '10px ui-monospace, monospace';
      ctx.textAlign = 'center';
      ctx.fillText(marker.label, p.x, p.y - Math.max(3, marker.radius * view.scale) - 3);
    }
  }

  for (const model of scene.models) {
    const colour = teamColour(model.teamOrdinal);
    path(ctx, model.shape, view, table);
    ctx.fillStyle = model.wounds > 0 ? '#1b1e24' : colour;
    ctx.globalAlpha = model.wounds > 0 ? 1 : 0.65;
    ctx.fill();
    ctx.globalAlpha = 1;
    ctx.strokeStyle = model.id === options.selected ? '#ffffff' : model.id === options.hovered ? '#e6e8ec' : colour;
    ctx.lineWidth = model.id === options.selected ? 2.5 : model.elevated ? 2 : 1;
    if (model.elevated) ctx.setLineDash([2, 2]);
    ctx.stroke();
    ctx.setLineDash([]);
    if (model.facing !== null) {
      ctx.strokeStyle = colour;
      ctx.lineWidth = 1.5;
      line(ctx, at(model.facing[0].x, model.facing[0].y), at(model.facing[1].x, model.facing[1].y));
    }
    if (options.showLabels && view.scale > 6) {
      const p = at(model.centre.x, model.centre.y);
      ctx.fillStyle = '#e6e8ec';
      ctx.font = '9px ui-monospace, monospace';
      ctx.textAlign = 'center';
      const tags = [model.wounds > 0 ? `-${model.wounds}` : '', ...model.conditions.map((c) => c[0]!)].filter(Boolean);
      if (tags.length > 0) ctx.fillText(tags.join(''), p.x, p.y - 2);
    }
  }

  ctx.restore();
}

function line(ctx: CanvasRenderingContext2D, a: { x: number; y: number }, b: { x: number; y: number }): void {
  ctx.beginPath();
  ctx.moveTo(a.x, a.y);
  ctx.lineTo(b.x, b.y);
  ctx.stroke();
}

function path(ctx: CanvasRenderingContext2D, shape: Shape, view: View, table: { width: number; length: number }): void {
  ctx.beginPath();
  if (shape.kind === 'circle') {
    const p = toScreen(view, table, shape.centre);
    ctx.arc(p.x, p.y, shape.radius * view.scale, 0, 2 * Math.PI);
    return;
  }
  shape.points.forEach((point, i) => {
    const p = toScreen(view, table, point);
    if (i === 0) ctx.moveTo(p.x, p.y);
    else ctx.lineTo(p.x, p.y);
  });
  ctx.closePath();
}

function shapeCentre(shape: Shape): { x: number; y: number } {
  if (shape.kind === 'circle') return shape.centre;
  const n = shape.points.length;
  return {
    x: shape.points.reduce((s, p) => s + p.x, 0) / n,
    y: shape.points.reduce((s, p) => s + p.y, 0) / n,
  };
}
```

```ts
// viewer/src/lib/timeline/timeline.ts

export type Timeline = {
  readonly count: number;
  /** -1 when there is no frame to show. */
  readonly index: number;
  readonly playing: boolean;
  readonly fps: number;
  /** Stick to the last frame as the feed grows. True for the live feed until the user steps or scrubs. */
  readonly follow: boolean;
};

export const EMPTY: Timeline = { count: 0, index: -1, playing: false, fps: 8, follow: false };

export type TimelineAction =
  | { readonly type: 'frames'; readonly count: number }
  | { readonly type: 'play' }
  | { readonly type: 'pause' }
  | { readonly type: 'toggle' }
  | { readonly type: 'tick' }
  | { readonly type: 'step'; readonly by: number }
  | { readonly type: 'scrub'; readonly index: number }
  | { readonly type: 'jump'; readonly seq: number; readonly seqs: readonly number[] }
  | { readonly type: 'first' }
  | { readonly type: 'last' }
  | { readonly type: 'fps'; readonly fps: number };

const clamp = (index: number, count: number): number => (count === 0 ? -1 : Math.min(count - 1, Math.max(0, index)));

export function reduce(state: Timeline, action: TimelineAction): Timeline {
  switch (action.type) {
    case 'frames': {
      const count = Math.max(0, action.count);
      const index = state.follow ? count - 1 : state.index;
      return { ...state, count, index: clamp(index, count) };
    }
    case 'play':
      return state.count === 0 ? state : { ...state, playing: true };
    case 'pause':
      return { ...state, playing: false };
    case 'toggle':
      return reduce(state, { type: state.playing ? 'pause' : 'play' });
    case 'tick': {
      if (!state.playing) return state;
      const next = state.index + 1;
      return next >= state.count
        ? { ...state, playing: false, index: clamp(state.index, state.count) }
        : { ...state, index: next };
    }
    case 'step':
      return { ...state, playing: false, follow: false, index: clamp(state.index + action.by, state.count) };
    case 'scrub':
      return { ...state, playing: false, follow: false, index: clamp(action.index, state.count) };
    case 'jump': {
      const found = indexOfSeq(action.seqs, action.seq);
      return { ...state, playing: false, follow: false, index: clamp(found, state.count) };
    }
    case 'first':
      return { ...state, playing: false, follow: false, index: clamp(0, state.count) };
    case 'last':
      return { ...state, playing: false, follow: true, index: clamp(state.count - 1, state.count) };
    case 'fps':
      return { ...state, fps: Math.min(60, Math.max(1, Math.round(action.fps))) };
  }
}

/** The frame at that event sequence, or the last frame before it. -1 when there are no frames. */
export function indexOfSeq(seqs: readonly number[], seq: number): number {
  if (seqs.length === 0) return -1;
  let answer = 0;
  for (let i = 0; i < seqs.length; i++) if (seqs[i]! <= seq) answer = i;
  return answer;
}

export function frameOf<T>(frames: readonly T[], t: Timeline): T | null {
  return t.index >= 0 && t.index < frames.length ? frames[t.index]! : null;
}
```

```ts
// viewer/src/lib/asks/describe.ts
import type { RecordedAsk, RecordedAskOption } from '../protocol/recording.generated';

export type Addressee = { readonly id: string; readonly label: string; readonly answered: boolean };

export type AskView = {
  readonly id: string;
  readonly heading: string;
  readonly prompt: string;
  readonly addressees: readonly Addressee[];
  readonly waitingOn: readonly string[];
  readonly legal: string;
  readonly notes: readonly string[];
  readonly options: readonly RecordedAskOption[];
  readonly pieces: readonly string[];
  readonly allowance: number | null;
};

export function humanise(question: string): string {
  if (question.length === 0) return '';
  const words = question.split('_').join(' ');
  return words[0]!.toUpperCase() + words.slice(1);
}

const plural = (n: number, one: string, many = `${one}s`): string => `${n} ${n === 1 ? one : many}`;

export function describeLegal(ask: RecordedAsk): string {
  switch (ask.legalKind) {
    case 'options': return plural(ask.options.length, 'option');
    case 'pieces': return `${plural(ask.pieces.length, 'eligible piece')}`;
    case 'allocation': return `${plural(ask.pieces.length, 'target')} to allocate over`;
    case 'assignment': return `${plural(ask.options.length, 'item')} over ${plural(ask.pieces.length, 'target')}`;
    case 'move_region': return `${plural(ask.pieces.length, 'model')} within ${ask.allowance ?? 0}"`;
    case 'bid': return `a bid of up to ${ask.allowance ?? 0}`;
    case 'confirmation': return 'yes or no';
    default: return ask.legalKind;
  }
}

export function describeAsk(ask: RecordedAsk, teamLabels: ReadonlyMap<string, string>): AskView {
  const answered = new Set(ask.answered);
  const addressees = ask.teams.map((id) => ({
    id, label: teamLabels.get(id) ?? `team ${id.slice(0, 8)}`, answered: answered.has(id),
  }));
  const notes: string[] = [];
  if (ask.allowPass) notes.push('a pass is allowed');
  if (ask.sealed) notes.push('sealed — answers stay hidden until it closes');
  if (ask.windowKind !== undefined) notes.push(`reaction window: ${ask.windowKind}`);
  if (ask.frameId !== undefined) notes.push(`in frame ${ask.frameId.slice(0, 8)}`);

  return {
    id: ask.id,
    heading: humanise(ask.question),
    prompt: ask.prompt,
    addressees,
    waitingOn: addressees.filter((a) => !a.answered).map((a) => a.label),
    legal: describeLegal(ask),
    notes,
    options: ask.options,
    pieces: ask.pieces,
    allowance: ask.allowance ?? null,
  };
}
```

```ts
// viewer/src/lib/feed/feed.ts
import type { RecordedBoard, RecordedFrame, RecordingMeta } from '../protocol/recording.generated';

export type FeedStatus = 'idle' | 'loading' | 'open' | 'closed' | 'error';

/** What every feed produces: the recording schema and nothing else, so the renderer cannot tell them apart. */
export type FeedState = {
  readonly label: string;
  readonly status: FeedStatus;
  readonly detail: string | null;
  readonly meta: RecordingMeta | null;
  readonly board: RecordedBoard | null;
  readonly frames: readonly RecordedFrame[];
};

export const IDLE: FeedState = { label: '', status: 'idle', detail: null, meta: null, board: null, frames: [] };

/**
 * The seam interactive debugging would use: pausing a run and answering an open Ask from the browser
 * (spec → Interactive debugging is a door, not a room). Nothing implements it. Both feeds return null,
 * and building it "makes the viewer a second thin client, which is a larger surface than a renderer".
 */
export type ControlChannel = {
  answer(askId: string, answer: unknown): void;
  resume(): void;
};

export interface Feed {
  readonly kind: 'recording' | 'live';
  readonly control: ControlChannel | null;
  subscribe(listener: (state: FeedState) => void): () => void;
  close(): void;
}

/** One subscriber list, one current state. Both feeds extend it; nothing else needs a store. */
export class Emitter {
  #state: FeedState;
  readonly #listeners = new Set<(state: FeedState) => void>();

  constructor(initial: FeedState) {
    this.#state = initial;
  }

  get state(): FeedState {
    return this.#state;
  }

  subscribe(listener: (state: FeedState) => void): () => void {
    this.#listeners.add(listener);
    listener(this.#state);
    return () => this.#listeners.delete(listener);
  }

  emit(next: Partial<FeedState>): void {
    this.#state = { ...this.#state, ...next };
    for (const listener of this.#listeners) listener(this.#state);
  }
}
```

```ts
import type { RecordingSource } from '../recording/source';
import { Emitter, IDLE, type ControlChannel, type Feed, type FeedState } from './feed';

export { IDLE } from './feed';
export type { FeedState } from './feed';

/** A recording arrives complete, so this feed emits once and never again. */
export function recordingFeed(source: RecordingSource): Feed {
  const emitter = new Emitter({
    ...IDLE,
    label: source.label,
    status: 'open',
    meta: source.recording.meta,
    board: source.recording.board,
    frames: source.recording.frames,
  });

  return {
    kind: 'recording',
    control: null as ControlChannel | null,
    subscribe: (listener: (state: FeedState) => void) => emitter.subscribe(listener),
    close: () => emitter.emit({ status: 'closed' }),
  };
}
```

**Files:**

**Interfaces:**
- Consumes: from `wire.generated.ts` — `Board`, `GameInfo`, `GameEvent`, `EventPayload`, `StateChange`, `Ask`, `AskAnswer`, `LegalSet`, `Location`, `Unit`, `ModelSlot`, `Marker`, `Grant`, `RollRecord`, `TerrainPlacement`, `Volume`; from `recording.generated.ts` — `RecordedBoard`, `RecordedFrame` and every `Recorded*` member; `DECLARATIONS` (Task 4).

- Produces (`logLines.ts`): `function lineOf(event: GameEvent, after: Projection, ordinals: ReadonlyMap<string, number>): string`; `function shortId(id: string): string`.
- Produces (`project.ts`): `function recordedBoardOf(board: Board, game: GameInfo): RecordedBoard`; `function declarationsOf(wire: string): readonly string[]`; `class FrameProjector` with `constructor(board: Board, game: GameInfo)`, `readonly board: RecordedBoard`, `add(event: GameEvent): RecordedFrame`, `get frames(): readonly RecordedFrame[]`, `get projection(): Projection`.
- These three files are the port `Tabletop.Protocol.EventApplier` (contracts plan Task 14), `Tabletop.Sim.Recording.LogLines` and `Tabletop.Sim.Recording.FrameProjector` (simulation plan Task 5) already are in C#. **They are a port, not a design**: every branch below matches a `case` in the C#, and Task 10 proves it by replaying a recording through both. Nothing here decides anything; the applier "copies. It never decides legality, never derives a location, never clears a store on its own."

Spec: spec → *Two feeds* — "the socket carries events, so the viewer must apply them, so `Tabletop.Protocol`'s message types and the event applier exist a second time in TypeScript. **Accepted, with the drift generated away where possible**."

**The resolution stack is not ported.** C#'s `Projection.Stack` holds `Frame`s so that `dice_rerolled`, `dice_edited` and `modifier_added` can amend a completed step's rolls. `RecordedFrame` carries no stack, and its `rolls` come from the `step_completed` payload rather than from the stack, so the C# recording does not show a reroll in `rolls` either — three event kinds therefore change nothing a frame records, and porting the stack would add code no field reads. `applyTo` handles those three kinds as no-ops with that reason on them, and `apply.test.ts` pins it.

```ts
// A port of Tabletop.Protocol.EventApplier (contracts plan Task 14), branch for branch.
// It copies. It never decides legality, never derives a location, never clears a store on its own.
import type {
  Board, GameEvent, GameInfo, Grant, Location, Marker, ModelSlot, StateChange, Unit,
} from '../protocol/wire.generated';
import type { Ask, AskAnswer } from '../protocol/wire.generated';

export type UnitInPlay = {
  readonly id: string; readonly participantId: string; readonly definition: Unit;
  readonly actions: Set<string>; readonly conditions: Set<string>;
  grants: Grant[]; woundsThisActivation: number;
};
export type ModelInPlay = {
  readonly id: string; readonly unitId: string; readonly slot: ModelSlot;
  location: Location; wounds: number; readonly conditions: Set<string>; spellTokens: number;
};
export type SchedulerPosition = {
  round: number; order: string[]; activeTeamId: string | undefined;
  phase: string | undefined; readonly passed: Set<string>;
};
export type OpenAsk = { readonly ask: Ask; readonly answers: Map<string, AskAnswer | undefined> };
export type Projection = {
  readonly board: Board;
  readonly units: Map<string, UnitInPlay>;
  readonly models: Map<string, ModelInPlay>;
  readonly markers: Map<string, Marker>;
  readonly scores: Map<string, number>;
  readonly scheduler: SchedulerPosition;
  readonly openAsks: Map<string, OpenAsk>;
  lastSeq: number;
};

export function initialProjection(board: Board, game: GameInfo): Projection {
  const p: Projection = {
    board,
    units: new Map(), models: new Map(), markers: new Map(), scores: new Map(),
    scheduler: { round: 0, order: [], activeTeamId: undefined, phase: undefined, passed: new Set() },
    openAsks: new Map(), lastSeq: 0,
  };
  for (const team of game.teams) p.scores.set(team.id, 0);
  // Insertion order matters: it is the order every frame lists models and units in, and C#'s
  // Projection.Initial walks armies, then units, then model slots in exactly this order.
  for (const army of board.armies)
    for (const unit of army.snapshot.units) {
      p.units.set(unit.id, {
        id: unit.id, participantId: army.participantId, definition: unit,
        actions: new Set(), conditions: new Set(), grants: [], woundsThisActivation: 0,
      });
      for (const slot of unit.models)
        p.models.set(slot.id, {
          id: slot.id, unitId: unit.id, slot, location: { kind: 'shelf' },
          wounds: 0, conditions: new Set(), spellTokens: 0,
        });
    }
  return p;
}

export function applyChange(p: Projection, change: StateChange): void {
  switch (change.kind) {
    case 'models_moved': for (const move of change.moves) p.models.get(move.modelId)!.location = move.to; return;
    case 'wounds_set': p.models.get(change.modelId)!.wounds = change.wounds; return;
    case 'condition_set': {
      const set = change.subject.kind === 'unit'
        ? p.units.get(change.subject.id)!.conditions
        : p.models.get(change.subject.id)!.conditions;
      if (change.present) set.add(change.condition); else set.delete(change.condition);
      return;
    }
    case 'action_recorded': p.units.get(change.unitId)!.actions.add(change.action); return;
    case 'action_record_cleared': p.units.get(change.unitId)!.actions.clear(); return;
    case 'grant_added': p.units.get(change.unitId)!.grants.push(change.grant); return;
    case 'grant_removed': {
      const unit = p.units.get(change.unitId)!;
      unit.grants = unit.grants.filter((g) => g.id !== change.grantId);
      return;
    }
    case 'spell_tokens_set': p.models.get(change.modelId)!.spellTokens = change.tokens; return;
    case 'wounds_this_activation_set': p.units.get(change.unitId)!.woundsThisActivation = change.wounds; return;
    case 'score_set': p.scores.set(change.teamId, change.score); return;
    case 'marker_placed': p.markers.set(change.marker.id, change.marker); return;
    case 'marker_moved': {
      const marker = p.markers.get(change.markerId)!;
      p.markers.set(change.markerId, { ...marker, position: change.position, yaw: change.yaw });
      return;
    }
    case 'marker_removed': p.markers.delete(change.markerId); return;
    default: throw new Error(`Unknown state change ${(change as { kind: string }).kind}`);
  }
}

const isStateChange = (payload: { kind: string }): payload is StateChange =>
  ['models_moved', 'wounds_set', 'condition_set', 'action_recorded', 'action_record_cleared', 'grant_added',
    'grant_removed', 'spell_tokens_set', 'wounds_this_activation_set', 'score_set', 'marker_placed',
    'marker_moved', 'marker_removed'].includes(payload.kind);

export function applyTo(p: Projection, event: GameEvent): void {
  const payload = event.payload;
  if (isStateChange(payload)) applyChange(p, payload);
  else switch (payload.kind) {
    case 'round_started':
      p.scheduler.round = payload.round;
      p.scheduler.order = [...payload.order];
      p.scheduler.activeTeamId = undefined;
      p.scheduler.passed.clear();
      for (const change of payload.changes) applyChange(p, change);
      break;
    case 'turn_started': p.scheduler.activeTeamId = payload.teamId; break;
    case 'turn_ended':
      if (payload.passed) p.scheduler.passed.add(payload.teamId);
      if (p.scheduler.activeTeamId === payload.teamId) p.scheduler.activeTeamId = undefined;
      for (const change of payload.changes) applyChange(p, change);
      break;
    case 'phase_started': p.scheduler.phase = payload.phase; break;
    case 'step_completed': for (const change of payload.changes) applyChange(p, change); break;
    case 'ask_opened': p.openAsks.set(payload.ask.id, { ask: payload.ask, answers: new Map() }); break;
    case 'ask_answered': p.openAsks.get(payload.askId)!.answers.set(payload.teamId, payload.answer); break;
    case 'ask_closed': p.openAsks.delete(payload.askId); break;
    // The frame stack is not ported: RecordedFrame carries no stack, and its rolls come from the
    // step_completed payload, so these four change nothing any field of a frame records.
    case 'sequence_started': case 'sequence_finished': case 'sequence_abandoned':
    case 'dice_rerolled': case 'dice_edited': case 'modifier_added': break;
    case 'undone': throw new Error('undone is applied by rebuilding; use Applier.apply');
    default: throw new Error(`Unknown payload ${(payload as { kind: string }).kind}`);
  }
  p.lastSeq = event.seq;
}

/** The log with every undone range removed. Undone markers never appear in the result. */
export function effectiveLog(log: readonly GameEvent[]): readonly GameEvent[] {
  const live: GameEvent[] = [];
  for (const event of log) {
    if (event.payload.kind === 'undone') {
      const to = event.payload.toSeq;
      for (let i = live.length - 1; i >= 0; i--) if (live[i]!.seq > to) live.splice(i, 1);
    } else live.push(event);
  }
  return live;
}

export class Applier {
  readonly #board: Board;
  readonly #game: GameInfo;
  readonly #log: GameEvent[] = [];
  #projection: Projection;

  constructor(board: Board, game: GameInfo) {
    this.#board = board;
    this.#game = game;
    this.#projection = initialProjection(board, game);
  }

  get log(): readonly GameEvent[] { return this.#log; }
  get projection(): Projection { return this.#projection; }

  apply(event: GameEvent): void {
    this.#log.push(event);
    if (event.payload.kind === 'undone') {
      const rebuilt = initialProjection(this.#board, this.#game);
      for (const live of effectiveLog(this.#log)) applyTo(rebuilt, live);
      rebuilt.lastSeq = event.seq;
      this.#projection = rebuilt;
    } else applyTo(this.#projection, event);
  }

  applyAll(events: Iterable<GameEvent>): void { for (const event of events) this.apply(event); }
}
```

```ts
export function shortId(id: string): string {
  return id.replace(/-/g, '').slice(0, 8);
}

const team = (ordinals: ReadonlyMap<string, number>, id: string): string =>
  ordinals.has(id) ? `Team ${ordinals.get(id)}` : shortId(id);
const unit = (p: Projection, id: string): string => p.units.get(id)?.definition.name ?? shortId(id);
const model = (p: Projection, id: string): string => p.models.get(id)?.slot.name ?? shortId(id);

/** C#'s "+#;-#;0" custom numeric format. */

  rolls.length === 0
    ? ''
    : `: ${rolls.map((r) => `${r.roll} ${r.dice.map((d) => (d.success ? `${d.modified}!` : `${d.modified}`)).join(',')}`).join('; ')}`;

  switch (answer.kind) {
    case 'chosen': return answer.optionId;
    case 'selected_pieces': return `${answer.pieceIds.length} piece(s)`;
    case 'allocated': return `${Object.values(answer.counts).reduce((a, b) => a + b, 0)} allocated`;

}
```

```ts
// viewer/src/lib/live/project.ts
// A port of Tabletop.Sim.Recording.FrameProjector (simulation plan Task 5): applies the events the socket
// delivered and writes down what the table looked like afterwards, in the recording's own shape.
import { DECLARATIONS } from '../board/palette';
import type {
  Ask, Board, GameEvent, GameInfo, ModelSlot, RollRecord, TerrainPlacement, VisualRef, Volume,
} from '../protocol/wire.generated';
import type {
  RecordedAsk, RecordedAskOption, RecordedBoard, RecordedFrame, RecordedModel, RecordedModelState,
  RecordedRoll, RecordedTerrain, RecordedUnitState, RecordedVolume,
} from '../protocol/recording.generated';
import { Applier, type ModelInPlay, type OpenAsk, type Projection, type UnitInPlay } from './apply';
import { lineOf } from './logLines';

/** The [Flags] wire form ("none", or "cover, impassable") in the canonical declaration order C# emits. */
export function declarationsOf(wire: string): readonly string[] {
  const present = new Set(wire.split(',').map((s) => s.trim()).filter((s) => s.length > 0 && s !== 'none'));
  return DECLARATIONS.filter((d) => present.has(d));
}

const visualName = (visual: VisualRef): string => visual.builtin ?? visual.assetId!;

function volumeOf(id: string, v: Volume): RecordedVolume {
  return {
    id, kind: v.kind, footprint: v.footprint.kind, a: v.footprint.a, b: v.footprint.b,
    offsetX: v.offset.x, offsetY: v.offset.y, yaw: v.yaw.degrees, bottom: v.bottom, top: v.top,
    declarations: declarationsOf(v.declarations),
    ...(v.notes === undefined ? {} : { notes: v.notes }),
  } as RecordedVolume;
}

function terrainOf(piece: TerrainPlacement): RecordedTerrain {
  return {
    id: piece.id, mesh: visualName(piece.mesh), x: piece.position.x, y: piece.position.y, z: piece.position.z,
    yaw: piece.yaw.degrees, scale: piece.scale, volumes: piece.volumes.map((v) => volumeOf(v.id, v.volume)),
  };
}

export function recordedBoardOf(board: Board, game: GameInfo): RecordedBoard {
  const table = board.table;
  const teamOf = new Map(game.participants.filter((p) => p.teamId !== undefined).map((p) => [p.id, p.teamId!]));
  const ordinalOf = new Map(game.teams.map((t) => [t.id, t.ordinal]));
  const models: RecordedModel[] = board.armies.flatMap((army) =>
    army.snapshot.units.flatMap((unit) =>
      unit.models.map((slot: ModelSlot) => {
        const teamId = teamOf.get(army.participantId)!;
        return {
          id: slot.id, unitId: unit.id, unitName: unit.name, name: slot.name, ordinal: slot.ordinal,
          teamId, teamOrdinal: ordinalOf.get(teamId)!,
          baseShape: slot.base.shape, baseA: slot.base.a, baseB: slot.base.b, height: slot.height,
        };
      }),
    ),
  );
  return {
    width: table.size.width, length: table.size.length, texture: visualName(table.texture),
    terrain: table.terrain.map(terrainOf),
    markers: table.markers.map((m) => ({
      id: m.id, kind: m.kind, diameter: m.diameter, ...(m.label === undefined ? {} : { label: m.label }),
    }) as RecordedBoard['markers'][number]),
    // The live feed resolves no zone: ZoneStyles is C# and is not ported (Task 4). An empty ring list
    // is what an unresolvable shape id produces C#-side too, and draws no outline rather than a wrong
    // one. Task 10's normaliseBoard drops `polygons` before comparing, and says why.
    zones: table.zones.map((z) => ({ id: z.id, shape: z.shape, teamOrdinal: z.teamOrdinal, polygons: [] })),
    models,
  };
}

const modelState = (m: ModelInPlay): RecordedModelState => {
  const common = { id: m.id, wounds: m.wounds, spellTokens: m.spellTokens, conditions: [...m.conditions].sort() };
  if (m.location.kind === 'table') {
    const { position, yaw } = m.location.placement;
    return { ...common, where: 'table', x: position.x, y: position.y, z: position.z, yaw: yaw.degrees } as RecordedModelState;
  }
  if (m.location.kind === 'inside')
    return { ...common, where: 'inside', containerId: m.location.containerId } as RecordedModelState;
  return { ...common, where: 'shelf' } as RecordedModelState;
};

const unitState = (u: UnitInPlay): RecordedUnitState => ({
  id: u.id, actions: [...u.actions].sort(), conditions: [...u.conditions].sort(),
  grants: u.grants.map((g) => g.entryName), woundsThisActivation: u.woundsThisActivation,
});

const optionOf = (o: { id: string; label: string; pieces: readonly string[] }): RecordedAskOption =>
  ({ id: o.id, label: o.label, pieces: o.pieces });

function askOf(open: OpenAsk): RecordedAsk {
  const ask: Ask = open.ask;
  const legal = ask.legal;
  let kind = legal.kind as string;
  let options: readonly RecordedAskOption[] = [];
  let pieces: readonly string[] = [];
  let allowance: number | undefined;
  switch (legal.kind) {
    case 'options': options = legal.choices.map(optionOf); break;
    case 'pieces': pieces = legal.eligible; break;
    case 'allocation': pieces = legal.targets; break;
    case 'assignment': options = legal.items.map(optionOf); pieces = legal.targets; break;
    case 'move_region': pieces = legal.modelIds; allowance = legal.allowance; break;
    case 'bid': allowance = legal.maxTokens; break;
    case 'confirmation': break;
    default: kind = legal.kind;
  }
  return {
    id: ask.id, question: ask.question, prompt: ask.prompt, teams: ask.teams,
    allowPass: ask.allowPass, sealed: ask.sealed,
    ...(ask.windowKind === undefined ? {} : { windowKind: ask.windowKind }),
    ...(ask.frameId === undefined ? {} : { frameId: ask.frameId }),
    legalKind: kind, answered: [...open.answers.keys()], options, pieces,
    ...(allowance === undefined ? {} : { allowance }),
  } as RecordedAsk;
}

const rollOf = (r: RollRecord): RecordedRoll => ({
  id: r.id, roll: r.roll, ...(r.threshold === undefined ? {} : { threshold: r.threshold }),
  net: r.dice.length === 0 ? 0 : r.dice[0]!.modified - r.dice[0]!.raw,
  raw: r.dice.map((d) => d.raw), modified: r.dice.map((d) => d.modified), success: r.dice.map((d) => d.success),
  modifiers: r.modifiers.map((m) => ({ source: m.source, amount: m.amount })),
}) as RecordedRoll;

export class FrameProjector {
  readonly #applier: Applier;
  readonly #ordinals: ReadonlyMap<string, number>;
  readonly #frames: RecordedFrame[] = [];
  readonly board: RecordedBoard;

  constructor(board: Board, game: GameInfo) {
    this.#applier = new Applier(board, game);
    this.#ordinals = new Map(game.teams.map((t) => [t.id, t.ordinal]));
    this.board = recordedBoardOf(board, game);
  }

  get frames(): readonly RecordedFrame[] { return this.#frames; }
  get projection(): Projection { return this.#applier.projection; }

  add(event: GameEvent): RecordedFrame {
    this.#applier.apply(event);
    const p = this.#applier.projection;
    const frame = {
      index: this.#frames.length, seq: event.seq, kind: event.payload.kind,
      ...(event.actor === undefined ? {} : { actor: event.actor }),
      ...(event.warning === undefined ? {} : { warning: event.warning }),
      round: p.scheduler.round,
      ...(p.scheduler.phase === undefined ? {} : { phase: p.scheduler.phase }),
      ...(p.scheduler.activeTeamId === undefined ? {} : { activeTeamId: p.scheduler.activeTeamId }),
      line: lineOf(event, p, this.#ordinals),
      models: [...p.models.values()].map(modelState),
      units: [...p.units.values()].map(unitState),
      markers: [...p.markers.values()].map((m) => ({
        id: m.id, kind: m.kind, diameter: m.diameter, ...(m.label === undefined ? {} : { label: m.label }),
        x: m.position.x, y: m.position.y, z: m.position.z, yaw: m.yaw.degrees,
      })),
      openAsks: [...p.openAsks.values()].map(askOf),
      rolls: event.payload.kind === 'step_completed' ? event.payload.rolls.map(rollOf) : [],
      // Copied, not aliased: every frame is kept for the whole run and the applier keeps mutating both.
      scores: Object.fromEntries(p.scores),
      passed: [...p.scheduler.passed],
    } as RecordedFrame;
    this.#frames.push(frame);
    return frame;
  }
}
```

`[...set].sort()` is JavaScript's code-unit order and C#'s `.Order()` is `Comparer<string>.Default`, which is culture-sensitive; the two agree for the ASCII identifiers conditions and actions actually use, and Task 10's comparison sorts both sides anyway, so a difference cannot produce a false failure. The same holds for `Map` insertion order versus `Dictionary` enumeration order after a marker or Ask is removed and another added.

```ts
// viewer/tests/normalise.ts
// C# Dictionary enumeration order and JavaScript Map insertion order can diverge once an entry is removed
// and another added (a marker taken off the table, an Ask closed), and C#'s .Order() is culture-sensitive
// where JavaScript's .sort() is by code unit. Neither is a drift in the applier, so both sides are
// normalised before comparison and everything else is compared exactly.
import type { RecordedBoard, RecordedFrame } from '../src/lib/protocol/recording.generated';

const byId = <T extends { id: string }>(items: readonly T[]): readonly T[] =>
  [...items].sort((a, b) => (a.id < b.id ? -1 : a.id > b.id ? 1 : 0));
const sorted = (items: readonly string[]): readonly string[] => [...items].sort();

export function normaliseFrame(frame: RecordedFrame): unknown {
  return {
    ...frame,
    models: byId(frame.models).map((m) => ({ ...m, conditions: sorted(m.conditions) })),
    units: byId(frame.units).map((u) => ({ ...u, actions: sorted(u.actions), conditions: sorted(u.conditions) })),
    markers: byId(frame.markers),
    openAsks: byId(frame.openAsks).map((a) => ({ ...a, answered: sorted(a.answered) })),
    passed: sorted(frame.passed),
  };
}

// `polygons` is the one field of the recording the live feed cannot produce and is not asked to:
// ZoneStyles.Resolve is C#, deliberately not ported (Task 4), so recordedBoardOf writes []. Dropping
// it here keeps the comparison honest about what is actually ported. Everything else about a zone —
// its id, its shape id, its team ordinal — is compared exactly.
export function normaliseBoard(board: RecordedBoard): unknown {
  return {
    ...board,
    markers: byId(board.markers),
    zones: byId(board.zones).map(({ polygons: _polygons, ...rest }) => rest),
    models: byId(board.models),
  };
}
```

```ts
// The only thing the viewer wants from the management API: a session JWT to put in Connect.
// POST /v1/auth/password and POST /v1/auth/session/refresh (management plan Task 5). Nothing else

export class ManagementError extends Error {}

export type Session = { readonly sessionJwt: string };

const base = (): string => import.meta.env.VITE_API_BASE ?? '';

async function post(path: string, body: unknown): Promise<Session> {
  const response = await fetch(`${base()}${path}`, {
    method: 'POST',
    headers: { 'content-type': 'application/json' },
    body: JSON.stringify(body),
  });
  if (!response.ok) {
    // Management answers application/problem+json (management plan Global Constraints).
    const problem = (await response.json().catch(() => ({}))) as { title?: string; detail?: string };
    throw new ManagementError(problem.detail ?? problem.title ?? `${path} answered ${response.status}`);
  }
  const session = (await response.json()) as { sessionJwt?: string };
  if (typeof session.sessionJwt !== 'string') throw new ManagementError(`${path} returned no sessionJwt`);
  return { sessionJwt: session.sessionJwt };
}
```

```ts
export const CLIENT_VERSION = 1;
const WELCOME_TIMEOUT_MS = 10_000;

/** Just enough of WebSocket to be replaceable in a test. */
export type SocketLike = {
  send(data: string): void;
  close(): void;
  addEventListener(type: string, handler: (event: never) => void): void;
};

export type LiveOptions = {
  readonly url: string;
  readonly gameId: string;
  readonly sessionJwt: string;
  readonly label?: string;
};

const HANDLED = new Set(['welcome', 'game', 'board', 'events', 'refused', 'rejected']);

export function isServerFrame(value: unknown): value is SocketMessage {
  return typeof value === 'object' && value !== null && HANDLED.has((value as { kind?: unknown }).kind as string);
}

/**
 * A live game, over the socket, attached as a participant with no team — a spectator who is never Asked
 * (spec → Two feeds). It sends Connect and nothing else, ever.
 */
export function liveFeed(
  options: LiveOptions,
  open: (url: string) => SocketLike = (url) => new WebSocket(url) as unknown as SocketLike,
): Feed {
  const started = Date.now();
  const emitter = new Emitter({ ...IDLE, label: options.label ?? `${options.url} · ${options.gameId}`, status: 'loading' });
  const socket = open(options.url);
  let game: GameInfo | null = null;
  let projector: FrameProjector | null = null;
  const pending: GameEvent[] = [];
  let welcomed = false;
  let failed = false;

  const timeout = setTimeout(() => {
    if (!welcomed) fail('no welcome within 10 s');
  }, WELCOME_TIMEOUT_MS);

  function fail(detail: string): void {
    failed = true;
    clearTimeout(timeout);
    emitter.emit({ status: 'error', detail });
  }

  function metaOf(info: GameInfo, lastSeq: number, rounds: number): RecordingMeta {
    const teams: RecordedTeam[] = info.teams.map((team) => ({
      id: team.id, ordinal: team.ordinal, name: `Team ${team.ordinal}`,
      participants: info.participants.filter((p) => p.teamId === team.id).map((p) => p.name),
    }));
    return {
      scenario: info.name, seed: 0, driver: 'live', gameRules: info.gameRules,
      propertiesHash: info.propertiesHash, schedulerShape: info.schedulerShape,
      enforcement: info.enforcement, teams, outcome: 'live',
      rounds, lastSeq, startedAt: new Date(started).toISOString(), durationMs: Date.now() - started,
    } as RecordingMeta;
  }

  function publish(): void {
    if (game === null || projector === null) return;
    const frames = projector.frames;
    const last = frames.length === 0 ? null : frames[frames.length - 1]!;
    emitter.emit({
      status: 'open', board: projector.board, frames: [...frames],
      meta: metaOf(game, last?.seq ?? 0, last?.round ?? 0),
    });
  }

  function drain(): void {
    if (projector === null) return;
    for (const event of pending.splice(0)) projector.add(event);
  }

  socket.addEventListener('open', () => {
    // The first frame, within 10 s of opening (game server plan → Client shell plan).
    socket.send(JSON.stringify({ kind: 'connect', sessionJwt: options.sessionJwt, gameId: options.gameId, clientVersion: CLIENT_VERSION }));
  });

  socket.addEventListener('message', (event: never) => {
    let parsed: unknown;
    try {
      parsed = JSON.parse((event as unknown as { data: string }).data);
    } catch {
      return;                                   // not our frame; the socket carries nothing else we read
    }
    if (!isServerFrame(parsed)) return;         // presence, ping, presence_ended: not read by the viewer
    const frame = parsed;
    switch (frame.kind) {
      case 'welcome':
        welcomed = true;
        clearTimeout(timeout);
        game = frame.game;
        // A game ended before setup ever ran sends no board, so status stays open with nothing to draw.
        emitter.emit({ status: 'open', meta: metaOf(frame.game, 0, 0) });
        return;
      case 'game':
        game = frame.game;
        publish();
        return;
      case 'board':
        if (game === null) return fail('a board arrived before the welcome');
        projector = new FrameProjector(frame.board as Board, game);
        drain();
        publish();
        return;
      case 'events':
        pending.push(...frame.events);
        drain();
        publish();
        return;
      case 'refused':
        emitter.emit({ detail: `refused: ${frame.reason} — ${frame.detail}` });
        return;
      case 'rejected':
        return fail(`rejected: ${frame.reason}`);
      default:
        return;
    }
  });

  socket.addEventListener('error', () => fail('the socket failed'));
  socket.addEventListener('close', () => {
    clearTimeout(timeout);
    if (!failed) emitter.emit({ status: 'closed' });
  });

  return {
    kind: 'live',
    control: null as ControlChannel | null,
    subscribe: (listener: (state: FeedState) => void) => emitter.subscribe(listener),
    close: () => {
      clearTimeout(timeout);
      socket.close();
      if (!failed) emitter.emit({ status: 'closed' });
    },
  };
}
```

`RecordingMeta.outcome` is set to `live`, a value the simulation plan's schema comment does not list; see *Spec corrections proposed*, item 3. Nothing about the shape changes — `outcome` is a `string`.

A `game` frame after teams change rebuilds nothing: `recordedBoardOf`'s team ordinals were resolved when the board arrived, so a team created mid-game does not recolour existing models. Lobby edits are refused from `playing` on (game server plan, question 1), so this cannot happen during a live game being watched.

### What is deliberately not built

No command, no Ask answer, no editing of anything, no pausing or resuming a run, no interactive control, and no auth beyond one spectator session JWT. The viewer sends exactly one frame in its whole life — `Connect` — and `Feed.control` is declared and `null` in both implementations. There is no 3D view, no mesh loading, no WebGL, no drawing library, no router, no SvelteKit, no service worker and no persistence: reloading the page loses the loaded recording, which is correct for a file the developer has on disk.

## Questions for the project owner

1. **Should `viewer/` be exercised by a headless browser test, or is "checked by looking at it" enough?** Assumed enough, exactly as the spec says (*Testing*: "The rendering is checked by looking at it"), so Vitest covers the pure modules and no Playwright or jsdom appears. That is also forced: `docs/handoff.md` records that headless Chrome cannot launch in this WSL image (missing `libnspr4`). If the rendering should be pinned, the cheapest version is a Node canvas shim producing a PNG per fixture frame and a byte comparison, which adds a native dependency to `viewer/` and roughly one task; nothing else in the plan moves.
2. **Two checked-in fixtures, at a two-round cap — the right size?** Assumed yes: `skirmish` and `terrain`, capped at two rounds, eight JSON files totalling a few hundred kilobytes, regenerated deliberately. A whole uncapped game is roughly 1.5 MB per recording, so four scenarios uncapped would be about 12 MB of checked-in JSON. If the fixtures should instead be generated on demand and never committed, `AgreementFixtureTests` always writes them, the agreement test needs a .NET SDK to have run first, and `npm test` alone stops being a complete check — which is why the plan chose committing them.
3. **Should the viewer offer to fetch a recording from the game server or management rather than from disk?** Assumed no: a recording is a `sim/` artifact on the developer's own filesystem, and neither server has any concept of one. `?recording=<url>` covers a static file server, which is all a shared recording needs. If recordings should be served, that is an endpoint on somebody's API and a new module concern rather than a viewer change.
4. **Should the viewer refuse to draw a recording whose `meta.gameRules` or `meta.propertiesHash` it has never seen?** Assumed no — it draws whatever the schema version admits and shows both values in the meta panel, because the viewer holds no ruleset and nothing it draws depends on one. Only `schemaVersion` gates the file. If a ruleset check is wanted it needs a list of known rulesets from somewhere, which the viewer has no source for.
5. **Is a two-pane layout with a tabbed side panel right, or should the log, the Ask and the dice all be visible at once?** Assumed tabbed — board on the left, one of log / Ask / dice / meta on the right, timeline across the bottom — because the log is the panel in constant use and the other three are consulted at a specific frame. Two things are exempt and sit in the header, outside the tabs, because they are wanted continuously: the source picker and `Scoreboard.svelte`, which carries the round, each team's score, and which team is active or has passed. If all four tabs should instead be stacked and visible, `App.svelte`'s right pane becomes a scrolling column and nothing else changes.
