# UX redesign: Home, Login, Create game, Settings

Spec: `docs/superpowers/specs/2026-11-07-ux-redesign-1-client-shell.md` → Login, Home, Create game, Settings; `-3-web.md` → Viewer → Games.
Index and vocabulary: `2026-11-07-ux-redesign-design.md`.

## Tasks

1. **Where a game stands, on the wire.** `libs/Tabletop.Protocol/GameProgress.cs`: `GameProgress(Round, ActingTeam, WaitingOn, Outcome)` and
   `GameProgress.Of(Projection, GameInfo)` (the scheduler's round and active team as an ordinal, the accounts of every addressed team that
   has not answered an open Ask, the winners' ordinals once ended), `SameAs`. Tests: `GameProgressTests`.
2. **The game server writes it.** Migration `server/management/Persistence/Migrations/031_game_progress.sql` adds `game.round`,
   `acting_team`, `waiting_on uuid[]`, `outcome int[]`. `IGameRows.WriteProgressAsync` (Postgres, the in-memory fake, the sim's
   `ScenarioRows`); `GameSession.WriteProgressAsync` after each run of the log and at hydration, when it differs from the session's last
   write. Tests: `GameRowsContract.Progress_is_written_and_rewritten_on_the_game_row` (fake and Postgres),
   `GameEndTests.The_row_carries_the_progress_after_hydration_and_after_the_end`. Docs: `docs/schema.md`, `docs/data-model.md`,
   `server/game/AGENTS.md`.
3. **Management lists it.** `GameSummary` gains `Teams`, `TeamsReady` (teams with a participant holding an army, for the lobby's
   `k of N teams ready`) and `Progress`. `GameRepository.List` and `InMemoryGameRepository.List`; `InMemoryRows` gains team rows.
   Tests: `RepositoryContract.Game_list_counts_teams_ready_and_carries_the_progress_the_game_server_wrote` (fake and Postgres). Docs:
   `server/management/AGENTS.md`, `docs/design/management-api/design.md`.
4. **Core `HomeView`** (replaces `GameRowActions`): the sections (Your games: joined, not ended; Open games: the rest not ended; Ended:
   joined and ended, only with Ended too), newest first, the name filter; per game `HomeCard` (edition from the rule set's name, three
   players then `+N`, the state line, primary Play / Continue / Open / Replay / Join, ▸ menu Replay / End game / Delete game / Leave),
   `Ago`. `CreateDefaults.EnforcementHint`, `NoArmy`, `NameShown`. Tests: `HomeViewTests`, `CreateDefaultsTests`.
5. **Godot `HomeScreen`**: header (TABLETOP, gear, account menu with Rename… and Sign out), New game, search, refresh, Ended too; cards
   (`HomeLook.Card`, `StatusMark`, `Primary`), rows; refresh on window focus. **Create game**: name problem from the first keystroke,
   enforcement line, *Choose in the lobby*, Create game primary and gated on the name; opens the lobby (as before).
6. **`LoginScreen`**: card, segmented Password / Email me a code, Sign in primary and a flat Create account, failures under their field,
   the gear. **`SettingsDialog`**: captioned groups, theme tiles in each theme's colours, key caps for the hitbox keys.
7. **Icons** `play`, `replay`, `menu`, `search`, `sign-out`, `add`, `refresh` for both themes; `UiThemes` list and its test counts.
8. **Viewer**: `viewer/src/lib/games/homeView.ts` (port of `HomeView`) and `tests/homeView.test.ts`; `GameSummary` / `GameProgress` in
   `live/games.ts`; `GamesPage.svelte` redrawn as cards and rows; `rowActions.ts`, `listsOf`, `mainActionOf`, `playersLine`,
   `ruleSetLine` removed.
9. **Docs**: `client/AGENTS.md`, `viewer/AGENTS.md`, `docs/design/client/core-and-screens.md`, `replay.md`, `rulings-and-references.md`.
