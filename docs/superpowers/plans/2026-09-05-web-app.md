# Web App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build `web/` — the Svelte SPA that owns preparation: login by password or email code against the management API, the account page and total deletion, armies imported from Army Forge and edited per unit and per slot, the asset library with nested folders, and the upload flow that converts STL to GLB in the browser, previews the result on a ring of the modelled base, and uploads by presigned URL.

**Architecture:** SvelteKit 2 on Svelte 5, built by `@sveltejs/adapter-static` as a pure SPA (`ssr = false`, `index.html` fallback) so `/reset-password?token=…` and `/armies/[id]` are real paths without a server. Every HTTP call goes through one typed client (`src/lib/api/`) whose request and response shapes are the management API plan's DTOs verbatim in camelCase. The mesh pipeline (`src/lib/mesh/`) is plain TypeScript over typed arrays — STL parse, merge, weld, decimate with the `meshoptimizer` WebAssembly simplifier, creased normals, GLB export with `@gltf-transform/core` — and runs headless under Vitest as well as inside a Web Worker in the page. three.js is used only to draw the preview and the top-down volume editor. Pages are thin over tested modules.

**Tech Stack:** Node 24 (`~/.local/share/mise`), npm; `svelte` 5.57.0, `@sveltejs/kit` 2.70.3, `@sveltejs/adapter-static` 3.0.10, `@sveltejs/vite-plugin-svelte` 7.3.0, `vite` 8.2.2, `vitest` 5.0.0, `typescript` 5.9.3, `svelte-check` 4.7.6; `meshoptimizer` 1.2.0 (WASM simplifier), `@gltf-transform/core` 4.5.0 (GLB read and write), `three` 0.185.1 + `@types/three` 0.185.4 (preview only).

**Spec:** `docs/superpowers/specs/2026-08-29-web-app-design.md` (primary); `2026-09-04-mesh-conversion-design.md`; `2026-08-28-army-design.md`; `2026-08-28-asset-library-design.md`; `2026-08-29-accounts-design.md`; `2026-08-29-management-api-design.md`; `2026-08-29-geometry-values-design.md`; `2026-08-29-content-values-design.md`; `2026-09-04-whole-design-review.md` (newest, wins); `docs/architecture.md` → Web frontend, Content and assets. ## Global Constraints

- The web app owns preparation only: armies, mesh binding, base shape and height, assets, folders, the account, login. **No game concepts**: it never calls `/v1/games*`, `/v1/properties` or `/v1/layouts` (web app → The line is preparation versus play).
- Every request goes to the management API's `/v1` surface exactly as `2026-09-05-management-api.md` → *Interfaces → Produces* lists it; JSON is camelCase with snake_case string enums and nulls omitted (`ContentJson.Configure`); errors are `application/problem+json`; pages are `Page<T>(items, next)` with `?limit=&after=`; another owner's row is `404`. No `Tabletop-Client-Version` header is sent: the version check exists because the Godot client "is a downloaded desktop application and a user can be months behind" (management API → The version check) and an SPA fetched on every load cannot be, and management accepts a missing header (management plan).
- Auth is the Stytch session JWT management returns; the web app stores it, refreshes it with `POST /v1/auth/session/refresh` once a minute (management API → "a JWT good for five minutes, refreshed every minute"), sends it as `Authorization: Bearer`, and holds no Stytch identifier or secret (accounts → Auth is a module, not a vendor).
- Login is email + password or email one-time code; no social login, no magic link (client shell ruling 09-04, web app → Login is the web app's). The `/reset-password` page reads `?token=` from Stytch's redirect and calls `POST /v1/auth/password/reset/complete` (management plan → Interfaces needed → Web-app plan).
- Units: the API speaks world units (inches); millimetres exist only in the UI — presets and the STL unit guess — and convert at the edge with `/ 25.4` (geometry values → Bases: "Millimetres never enter the model").
- Frame: Z is up, yaw 0 faces +Y, positive yaw is counter-clockwise from above, an oval's `a` (length) lies along the facing axis (geometry plan → Coordinate frame). glTF is Y-up, so the preview and the volume editor rotate the world, never the data.
- Mesh conversion runs in the browser and nothing uploads before the user has seen the preview; budgets 15,000 triangles (miniature) and 50,000 (terrain); supports are warned about and never removed; the converter proposes scale, orientation and modelled base and the user confirms (mesh conversion → The flow, What conversion does, What it writes).
- Upload sequence, exactly: SHA-256 in the browser → `POST /v1/assets` → if `uploadUrl` is present, `PUT` the bytes to it with the declared `Content-Type` → `POST /v1/assets/{id}/confirm` → show `warning` → for terrain, `PUT /v1/assets/{id}/volumes` with the bounding-box volume (management plan Tasks 6–7; mesh conversion → What it does not do).
- GLB is the only mesh format uploaded (`model/gltf-binary`); textures are `image/png` or `image/jpeg`; STL is converted first and never sent (management API → GLB only).
- A changed list means a re-import: no reconciliation, per-slot bindings are lost and the UI says so (the army → A changed list means a re-import).
- TypeScript strict; Vitest for every module with logic (`src/lib/**`); Svelte pages are tested by running the app. Commit after every task (imperative one-line message, `Co-Authored-By` and `Claude-Session` trailers).
- `web/` is a deliverable and contains only the SPA; nothing under `web/` is referenced by `Tabletop.sln`.

- Decision — **SvelteKit + adapter-static, not plain Vite + Svelte**: the app needs real paths (`/reset-password?token=` is what Stytch redirects to, and a hash router would put the query before the `#`), per-page code splitting for the three.js and WASM bundles, and file-based routing; `ssr = false` everywhere keeps it a pure SPA — no server, no `load` on the server, static files only (web app → Deliberately not decided: "framework details beyond it being a Svelte SPA" — this settles them). The `/v1` proxy keeps development same-origin; management also answers CORS for `TABLETOP_WEB_URL` (management plan Task 3, this plan's request under *Interfaces needed*), so a built SPA served from another origin works with `PUBLIC_API_BASE` set to management's URL; presigned MinIO URLs are absolute and MinIO answers CORS itself.

Spec: `architecture.md` → Deliverables (`web/`, "Static (Svelte SPA)"), Repository layout ("The Svelte app shares no code with the .NET projects"); management plan Task 1 (`TABLETOP_WEB_URL=http://localhost:5173`).

```ts
import type { Problem } from './types';

export const API_BASE: string = (import.meta.env?.PUBLIC_API_BASE as string | undefined) ?? '';

export class ApiError extends Error {
  constructor(public status: number, public title: string, public detail?: string) { super(detail ?? title); }
}

let tokenProvider: () => string | null = () => null;
export function setTokenProvider(p: () => string | null) { tokenProvider = p; }

async function send<T>(method: string, path: string, body?: unknown): Promise<T> {
  const headers = new Headers({ accept: 'application/json' });
  if (body !== undefined) headers.set('content-type', 'application/json');
  const token = tokenProvider();
  const isAuthRoute = path.startsWith('/v1/auth/') && !(method === 'DELETE' && path === '/v1/auth/session');
  if (token && !isAuthRoute) headers.set('authorization', `Bearer ${token}`);
  const response = await fetch(API_BASE + path, { method, headers, body: body === undefined ? undefined : JSON.stringify(body) });
  if (response.ok) { const text = await response.text(); return (text ? JSON.parse(text) : undefined) as T; }   // 202 and 204 carry no body
  let problem: Problem = {};
  try { problem = (await response.json()) as Problem; } catch { /* no body */ }
  if (response.status === 401 && !isAuthRoute) http.onUnauthorized();
  throw new ApiError(response.status, problem.title ?? response.statusText, problem.detail);
}

export const http = {
  onUnauthorized: (() => {}) as () => void,
  get: <T>(path: string) => send<T>('GET', path),
  post: <T>(path: string, body?: unknown) => send<T>('POST', path, body ?? {}),
  put: <T>(path: string, body?: unknown) => send<T>('PUT', path, body),
  patch: <T>(path: string, body: unknown) => send<T>('PATCH', path, body),
  del: <T = void>(path: string) => send<T>('DELETE', path),
};

export function query(params: Record<string, string | number | undefined>): string {
  const q = Object.entries(params).filter(([, v]) => v !== undefined && v !== '').map(([k, v]) => `${k}=${encodeURIComponent(String(v))}`).join('&');
  return q ? `?${q}` : '';
}
```

```ts
// web/src/lib/session/jwt.ts — the JWT is opaque to us except for when it expires. Nothing here verifies it; management does.
export function decodeExp(jwt: string): number | null {
  const parts = jwt.split('.');
  if (parts.length !== 3) return null;
  try {
    const json = atob(parts[1]!.replace(/-/g, '+').replace(/_/g, '/'));
    const exp = (JSON.parse(json) as { exp?: unknown }).exp;
    return typeof exp === 'number' ? exp : null;
  } catch { return null; }
}

/** Once a minute, but never later than 30 s before expiry, and at once when already expired. */
export function refreshDelayMs(exp: number | null, nowMs = Date.now(), { intervalMs = 60_000, marginMs = 30_000 } = {}): number {
  if (exp === null) return intervalMs;
  const untilExpiry = exp * 1000 - nowMs;
  return Math.max(0, Math.min(intervalMs, untilExpiry - marginMs));
}
```

```ts
// web/src/lib/session/session.svelte.ts
import { api } from '$lib/api/client';
import { http, setTokenProvider } from '$lib/api/http';
import type { AccountRow, SessionResponse } from '$lib/api/types';
import { decodeExp, refreshDelayMs } from './jwt';

export const STORAGE_KEY = 'tabletop.session';

function read(): SessionResponse | null {
  try { const raw = localStorage.getItem(STORAGE_KEY); return raw ? (JSON.parse(raw) as SessionResponse) : null; } catch { return null; }
}

class Session {
  token = $state<string | null>(null);
  account = $state<AccountRow | null>(null);
  ready = $state(false);

  constructor() {
    setTokenProvider(() => this.token);
    http.onUnauthorized = () => this.clear();
  }

  accept(s: SessionResponse) {
    this.token = s.sessionJwt;
    this.account = s.account;
    localStorage.setItem(STORAGE_KEY, JSON.stringify(s));
  }

  clear() {
    this.token = null;
    this.account = null;
    localStorage.removeItem(STORAGE_KEY);
  }

  async restore() {
    const stored = read();
    if (stored) { this.token = stored.sessionJwt; this.account = stored.account; await this.refresh(); }
    this.ready = true;
  }

  /** A fresh five-minute JWT from the long-lived Stytch session. False (and signed out) when management refuses. */
  async refresh(): Promise<boolean> {
    if (!this.token) return false;
    try { this.accept(await api.auth.refresh(this.token)); return true; }
    catch { this.clear(); return false; }
  }

  async logout() {
    try { await api.auth.logout(); } catch { /* the token may already be dead; clearing is what matters */ }
    this.clear();
  }

  /** Schedules refreshes from the token's exp; returns a stop function for onDestroy. */
  startRefreshLoop(): () => void {
    let timer: ReturnType<typeof setTimeout> | undefined;
    const tick = async () => {
      if (!this.token) { timer = setTimeout(tick, 60_000); return; }
      await this.refresh();
      timer = setTimeout(tick, refreshDelayMs(this.token ? decodeExp(this.token) : null));
    };
    timer = setTimeout(tick, refreshDelayMs(this.token ? decodeExp(this.token) : null));
    return () => clearTimeout(timer);
  }
}

export const session = new Session();
```

```ts
// web/src/lib/session/messages.ts
import { ApiError } from '$lib/api/http';
export function loginErrorMessage(e: unknown): string {
  if (!(e instanceof ApiError)) return 'Something went wrong. Try again.';
  switch (e.status) {
    case 401: return 'Wrong email, password or code.';
    case 409: return 'An account with that email already exists — sign in instead.';
    case 422: return e.detail ?? e.title;
    default: return e.title;
  }
}
```

```ts
import { inchesToMm, mmToInches, round } from './units';

export interface BasePreset { label: string; base: Base }

export const oval = (lengthMm: number, widthMm: number): Base => ({ shape: 'oval', a: mmToInches(lengthMm), b: mmToInches(widthMm) });

];
```

```ts
export type Vec3 = [number, number, number];
export interface IndexedMesh { positions: Float32Array; indices: Uint32Array; normals?: Float32Array }
export interface Bounds { min: Vec3; max: Vec3 }
export const triangleCount = (m: IndexedMesh) => m.indices.length / 3;
export function bounds(positions: Float32Array): Bounds {
  const min: Vec3 = [Infinity, Infinity, Infinity], max: Vec3 = [-Infinity, -Infinity, -Infinity];
  for (let i = 0; i < positions.length; i += 3) for (let k = 0; k < 3; k++) { const v = positions[i + k]!; if (v < min[k]!) min[k] = v; if (v > max[k]!) max[k] = v; }
  return { min, max };
}
```

```ts
// web/src/lib/mesh/stl.ts — STL in, triangle soup out (9 floats per triangle). Per-face normals are discarded; Task 8 recomputes them.
export class StlError extends Error {}

export function parseStl(buffer: ArrayBuffer): Float32Array {
  if (buffer.byteLength >= 84) {
    const count = new DataView(buffer).getUint32(80, true);
    if (84 + 50 * count === buffer.byteLength) return parseBinary(buffer, count);
  }
  const text = new TextDecoder('latin1').decode(new Uint8Array(buffer, 0, Math.min(buffer.byteLength, 512)));
  if (/^\s*solid/.test(text)) return parseAscii(new TextDecoder().decode(buffer));
  throw new StlError('Not an STL file: neither a binary facet table nor an ASCII "solid".');
}

function parseBinary(buffer: ArrayBuffer, count: number): Float32Array {
  const view = new DataView(buffer), out = new Float32Array(count * 9);
  for (let i = 0; i < count; i++) {
    const o = 84 + 50 * i + 12;                                   // skip the facet normal
    for (let k = 0; k < 9; k++) out[i * 9 + k] = view.getFloat32(o + 4 * k, true);
  }
  return out;
}

function parseAscii(text: string): Float32Array {
  const values: number[] = [];
  const re = /vertex\s+([-+.\deE]+)\s+([-+.\deE]+)\s+([-+.\deE]+)/g;
  for (let m = re.exec(text); m; m = re.exec(text)) values.push(Number(m[1]), Number(m[2]), Number(m[3]));
  if (values.length === 0 || values.length % 9 !== 0) throw new StlError('ASCII STL has no complete facets.');
  return Float32Array.from(values);
}

/** Kits ship as parts already placed relative to each other; merging is concatenation and no fitting is attempted. */
export function mergeSoups(parts: Float32Array[]): Float32Array {
  const out = new Float32Array(parts.reduce((n, p) => n + p.length, 0));
  let o = 0; for (const p of parts) { out.set(p, o); o += p.length; }
  return out;
}
```

```ts
// web/src/lib/mesh/weld.ts — exact welding on the float bits with a spatial hash; STL exporters repeat corners bit-for-bit.
import type { IndexedMesh } from './types';

export function weld(soup: Float32Array): IndexedMesh {
  const bits = new Uint32Array(soup.buffer, soup.byteOffset, soup.length);
  const buckets = new Map<number, number[]>();
  const positions: number[] = [], indices: number[] = [];
  const cornerCount = soup.length / 3;
  const remap = new Uint32Array(cornerCount);
  for (let c = 0; c < cornerCount; c++) {
    const x = bits[c * 3]!, y = bits[c * 3 + 1]!, z = bits[c * 3 + 2]!;
    const h = (Math.imul(x, 73856093) ^ Math.imul(y, 19349663) ^ Math.imul(z, 83492791)) >>> 0;
    let bucket = buckets.get(h);
    if (!bucket) buckets.set(h, (bucket = []));
    let found = -1;
    for (const v of bucket) if (positions[v * 3] === soup[c * 3] && positions[v * 3 + 1] === soup[c * 3 + 1] && positions[v * 3 + 2] === soup[c * 3 + 2]) { found = v; break; }
    if (found < 0) { found = positions.length / 3; positions.push(soup[c * 3]!, soup[c * 3 + 1]!, soup[c * 3 + 2]!); bucket.push(found); }
    remap[c] = found;
  }
  for (let t = 0; t < cornerCount; t += 3) {
    const a = remap[t]!, b = remap[t + 1]!, c = remap[t + 2]!;
    if (a !== b && b !== c && a !== c) indices.push(a, b, c);
  }
  return { positions: Float32Array.from(positions), indices: Uint32Array.from(indices) };
}
```

```ts
// web/src/lib/mesh/decimate.ts — meshoptimizer's simplifier, widened until the budget is met.
import { MeshoptSimplifier } from 'meshoptimizer';
import type { IndexedMesh } from './types';
import { triangleCount } from './types';

export const BUDGETS = { miniature: 15_000, terrain: 50_000 } as const;
const ERRORS = [0.005, 0.01, 0.02, 0.05, 0.1, 0.25, 0.5];

export async function decimate(mesh: IndexedMesh, budgetTriangles: number): Promise<IndexedMesh> {
  if (triangleCount(mesh) <= budgetTriangles) return mesh;
  await MeshoptSimplifier.ready;
  let best = mesh.indices;
  for (const error of ERRORS) {
    const [indices] = MeshoptSimplifier.simplify(mesh.indices, mesh.positions, 3, budgetTriangles * 3, error);
    best = indices;
    if (indices.length / 3 <= budgetTriangles) break;
  }
  return compact({ positions: mesh.positions, indices: best });
}

/** Drops vertices no triangle references any more. */
export function compact(mesh: IndexedMesh): IndexedMesh {
  const [remap, unique] = MeshoptSimplifier.compactMesh(mesh.indices);
  const positions = new Float32Array(unique * 3);
  for (let v = 0; v < mesh.positions.length / 3; v++) {
    const to = remap[v]!;
    if (to === 0xffffffff) continue;
    positions.set(mesh.positions.subarray(v * 3, v * 3 + 3), to * 3);
  }
  const indices = new Uint32Array(mesh.indices.length);
  for (let i = 0; i < indices.length; i++) indices[i] = remap[mesh.indices[i]!]!;
  return { positions, indices };
}
```

```ts
// web/src/lib/mesh/normals.ts — per-corner normals averaged over the incident faces within the crease angle, then re-welded on (position, normal).
import type { IndexedMesh } from './types';

export function creasedNormals(mesh: IndexedMesh, angleDegrees = 60): IndexedMesh {
  const { positions, indices } = mesh;
  const faceCount = indices.length / 3, faceNormals = new Float32Array(faceCount * 3);
  const incident: number[][] = Array.from({ length: positions.length / 3 }, () => []);
  for (let f = 0; f < faceCount; f++) {
    const [a, b, c] = [indices[f * 3]!, indices[f * 3 + 1]!, indices[f * 3 + 2]!];
    const ax = positions[a * 3]!, ay = positions[a * 3 + 1]!, az = positions[a * 3 + 2]!;
    const ux = positions[b * 3]! - ax, uy = positions[b * 3 + 1]! - ay, uz = positions[b * 3 + 2]! - az;
    const vx = positions[c * 3]! - ax, vy = positions[c * 3 + 1]! - ay, vz = positions[c * 3 + 2]! - az;
    let nx = uy * vz - uz * vy, ny = uz * vx - ux * vz, nz = ux * vy - uy * vx;
    const len = Math.hypot(nx, ny, nz) || 1; nx /= len; ny /= len; nz /= len;
    faceNormals.set([nx, ny, nz], f * 3);
    incident[a]!.push(f); incident[b]!.push(f); incident[c]!.push(f);
  }
  const cosThreshold = Math.cos((angleDegrees * Math.PI) / 180);
  const outPositions: number[] = [], outNormals: number[] = [], outIndices = new Uint32Array(indices.length);
  const seen = new Map<string, number>();
  for (let f = 0; f < faceCount; f++) for (let k = 0; k < 3; k++) {
    const v = indices[f * 3 + k]!;
    let nx = 0, ny = 0, nz = 0;
    for (const g of incident[v]!) {
      const dot = faceNormals[f * 3]! * faceNormals[g * 3]! + faceNormals[f * 3 + 1]! * faceNormals[g * 3 + 1]! + faceNormals[f * 3 + 2]! * faceNormals[g * 3 + 2]!;
      if (dot >= cosThreshold) { nx += faceNormals[g * 3]!; ny += faceNormals[g * 3 + 1]!; nz += faceNormals[g * 3 + 2]!; }
    }
    const len = Math.hypot(nx, ny, nz) || 1; nx /= len; ny /= len; nz /= len;
    const key = `${v}|${nx.toFixed(4)}|${ny.toFixed(4)}|${nz.toFixed(4)}`;
    let idx = seen.get(key);
    if (idx === undefined) { idx = outPositions.length / 3; seen.set(key, idx); outPositions.push(positions[v * 3]!, positions[v * 3 + 1]!, positions[v * 3 + 2]!); outNormals.push(nx, ny, nz); }
    outIndices[f * 3 + k] = idx;
  }
  return { positions: Float32Array.from(outPositions), normals: Float32Array.from(outNormals), indices: outIndices };
}
```

```ts
import { Document, WebIO } from '@gltf-transform/core';
import type { IndexedMesh } from './types';

const io = new WebIO();

export async function exportGlb(mesh: IndexedMesh, name: string): Promise<Uint8Array> {
  if (!mesh.normals) throw new Error('exportGlb needs normals; run creasedNormals first.');
  const doc = new Document();
  const buffer = doc.createBuffer();
  const position = doc.createAccessor('POSITION').setType('VEC3').setArray(mesh.positions).setBuffer(buffer);
  const normal = doc.createAccessor('NORMAL').setType('VEC3').setArray(mesh.normals).setBuffer(buffer);
  const indices = doc.createAccessor('indices').setType('SCALAR').setArray(mesh.indices).setBuffer(buffer);
  const material = doc.createMaterial('default').setBaseColorFactor([0.8, 0.8, 0.8, 1]).setMetallicFactor(0).setRoughnessFactor(0.8);
  const primitive = doc.createPrimitive().setAttribute('POSITION', position).setAttribute('NORMAL', normal).setIndices(indices).setMaterial(material);
  const node = doc.createNode(name).setMesh(doc.createMesh(name).addPrimitive(primitive));
  doc.createScene(name).addChild(node);
  doc.getRoot().getAsset().generator = 'tabletop-web mesh conversion';
  return io.writeBinary(doc);
}

/** Every primitive's positions in world space, and the triangle total management's header read will report. */
export async function readGlb(bytes: Uint8Array): Promise<{ positions: Float32Array; triangles: number }> {
  const doc = await io.readBinary(bytes);
  const chunks: Float32Array[] = [];
  let triangles = 0;
  for (const mesh of doc.getRoot().listMeshes()) for (const prim of mesh.listPrimitives()) {
    const count = (prim.getIndices() ?? prim.getAttribute('POSITION'))?.getCount() ?? 0;
    const mode = prim.getMode();
    triangles += mode === 4 ? Math.floor(count / 3) : mode === 5 || mode === 6 ? Math.max(0, count - 2) : 0;
  }
  for (const node of doc.getRoot().listNodes()) {
    const mesh = node.getMesh(); if (!mesh) continue;
    const m = node.getWorldMatrix();
    for (const prim of mesh.listPrimitives()) {
      const src = prim.getAttribute('POSITION')?.getArray() as Float32Array | null; if (!src) continue;
      const out = new Float32Array(src.length);
      for (let i = 0; i < src.length; i += 3) {
        const x = src[i]!, y = src[i + 1]!, z = src[i + 2]!;
        out[i] = m[0]! * x + m[4]! * y + m[8]! * z + m[12]!; out[i + 1] = m[1]! * x + m[5]! * y + m[9]! * z + m[13]!; out[i + 2] = m[2]! * x + m[6]! * y + m[10]! * z + m[14]!;
      }
      chunks.push(out);
    }
  }
  const positions = new Float32Array(chunks.reduce((n, c) => n + c.length, 0));
  let o = 0; for (const c of chunks) { positions.set(c, o); o += c.length; }
  return { positions, triangles };
}
```

```ts
// web/src/lib/mesh/guess.ts — STL has no units and no up-axis; propose millimetres and the axis along which the model is tall.
import type { Orientation } from '$lib/api/types';
import { mmToInches } from '$lib/units/units';
import { type Bounds, type IndexedMesh, bounds } from './types';

export type UpAxis = 'y' | 'z';
export interface Proposal { scale: number; orientation: Orientation; upAxis: UpAxis; unitsGuess: 'mm' }

const size = (b: Bounds, k: 0 | 1 | 2) => b.max[k]! - b.min[k]!;

export function guessUpAxis(b: Bounds): UpAxis {
  const [sx, sy, sz] = [size(b, 0), size(b, 1), size(b, 2)];
  const tallY = sy > Math.max(sx, sz), tallZ = sz > Math.max(sx, sy);
  return tallY && !tallZ ? 'y' : 'z';
}

export function propose(b: Bounds): Proposal {
  const upAxis = guessUpAxis(b);
  return { scale: mmToInches(1), orientation: upAxis === 'y' ? { pitch: 90, yaw: 0, roll: 0 } : { pitch: 0, yaw: 0, roll: 0 }, upAxis, unitsGuess: 'mm' };
}

/** Centres the footprint on the origin and puts the lowest point at zero, in mesh space, so the model stands on its base at the origin. */
export function recentre(mesh: IndexedMesh, up: UpAxis): IndexedMesh {
  const b = bounds(mesh.positions), upIndex = up === 'y' ? 1 : 2;
  const shift = [0, 1, 2].map((k) => (k === upIndex ? b.min[k]! : (b.min[k]! + b.max[k]!) / 2));
  for (let i = 0; i < mesh.positions.length; i += 3) for (let k = 0; k < 3; k++) mesh.positions[i + k] = mesh.positions[i + k]! - shift[k]!;
  return mesh;
}

/** Rotates a mesh-space point into the table frame: pitch about X, then roll about Y, then yaw about Z (degrees, right-handed), then scales. */
export function toWorld([x, y, z]: [number, number, number], p: { scale: number; orientation: Orientation }): [number, number, number] {
  const r = (d: number) => (d * Math.PI) / 180;
  const [cp, sp, cr, sr, cy, sy] = [Math.cos(r(p.orientation.pitch)), Math.sin(r(p.orientation.pitch)), Math.cos(r(p.orientation.roll)), Math.sin(r(p.orientation.roll)), Math.cos(r(p.orientation.yaw)), Math.sin(r(p.orientation.yaw))];
  let [px, py, pz] = [x, y * cp - z * sp, y * sp + z * cp];                 // pitch about X
  [px, py, pz] = [px * cr + pz * sr, py, -px * sr + pz * cr];               // roll about Y
  [px, py, pz] = [px * cy - py * sy, px * sy + py * cy, pz];                // yaw about Z
  return [px * p.scale, py * p.scale, pz * p.scale];
}

/** The model's extent in the table frame, from the eight corners of its mesh-space bounds. */
export function worldExtent(b: Bounds, p: { scale: number; orientation: Orientation }): { width: number; length: number; height: number; min: [number, number, number]; max: [number, number, number] } {
  const min: [number, number, number] = [Infinity, Infinity, Infinity], max: [number, number, number] = [-Infinity, -Infinity, -Infinity];
  for (const x of [b.min[0]!, b.max[0]!]) for (const y of [b.min[1]!, b.max[1]!]) for (const z of [b.min[2]!, b.max[2]!]) {
    const w = toWorld([x, y, z], p);
    for (let k = 0; k < 3; k++) { min[k] = Math.min(min[k]!, w[k]!) ; max[k] = Math.max(max[k]!, w[k]!); }
  }
  return { width: max[0] - min[0], length: max[1] - min[1], height: max[2] - min[2], min, max };
}
```

```ts
// web/src/lib/mesh/supports.ts — the signature of print supports: many thin, tall, disconnected components standing on the bottom. Detected, never removed.
import { guessUpAxis } from './guess';
import type { IndexedMesh } from './types';
import { bounds } from './types';

export interface SupportReport { suspected: boolean; components: number; supportLike: number }

export function detectSupports(mesh: IndexedMesh, { thinFraction = 0.06, tallRatio = 3, floorFraction = 0.02, minCount = 6 } = {}): SupportReport {
  const n = mesh.positions.length / 3, parent = new Uint32Array(n).map((_, i) => i);
  const find = (i: number): number => { while (parent[i] !== i) { parent[i] = parent[parent[i]!]!; i = parent[i]!; } return i; };
  const union = (a: number, b: number) => { a = find(a); b = find(b); if (a !== b) parent[a] = b; };
  for (let t = 0; t < mesh.indices.length; t += 3) { union(mesh.indices[t]!, mesh.indices[t + 1]!); union(mesh.indices[t]!, mesh.indices[t + 2]!); }
  const all = bounds(mesh.positions), up = guessUpAxis(all) === 'y' ? 1 : 2, h = ([0, 1, 2] as const).filter((k) => k !== up);
  const modelHeight = all.max[up]! - all.min[up]!, modelWidth = Math.max(all.max[h[0]!]! - all.min[h[0]!]!, all.max[h[1]!]! - all.min[h[1]!]!);
  const comp = new Map<number, { min: [number, number, number]; max: [number, number, number] }>();
  for (let v = 0; v < n; v++) {
    const root = find(v); let c = comp.get(root);
```

```ts
// web/src/lib/mesh/convert.ts — the pipeline, in the spec's order: parse, merge, weld, decimate, normals, export, then the analysis the preview needs.
import type { Volume } from '$lib/api/types';
import { terrainVolume } from './bounds';
import { BUDGETS, decimate } from './decimate';
import { exportGlb, readGlb } from './glb';
import { type Proposal, guessUpAxis, propose, recentre } from './guess';
import { creasedNormals } from './normals';
import { mergeSoups, parseStl } from './stl';
import { type SupportReport, detectSupports } from './supports';
import { type Bounds, bounds, triangleCount } from './types';
import { weld } from './weld';

export interface ConversionInput { kind: 'miniature' | 'terrain'; budget?: number; creaseAngle?: number; files: { name: string; bytes: ArrayBuffer }[] }
export interface ConversionResult { glb: Uint8Array; trianglesBefore: number; trianglesAfter: number; bounds: Bounds; proposal: Proposal; supports: SupportReport; volume: Volume }
export type Progress = { step: 'parse' | 'weld' | 'decimate' | 'normals' | 'export' | 'analyse' };

export async function convert(input: ConversionInput, onProgress: (p: Progress) => void = () => {}): Promise<ConversionResult> {
  onProgress({ step: 'parse' });
  const soup = mergeSoups(input.files.map((f) => parseStl(f.bytes)));
  onProgress({ step: 'weld' });                                    // weld, then centre on the footprint (spec correction 3)
  const raw = weld(soup);
  const welded = recentre(raw, guessUpAxis(bounds(raw.positions)));
  const trianglesBefore = triangleCount(welded);
  const supports = detectSupports(welded);                       // on the full mesh: decimation can merge thin pillars
  onProgress({ step: 'decimate' });
  const decimated = await decimate(welded, input.budget ?? BUDGETS[input.kind]);
  onProgress({ step: 'normals' });
  const shaded = creasedNormals(decimated, input.creaseAngle ?? 60);
  onProgress({ step: 'export' });
  const glb = await exportGlb(shaded, input.files[0]?.name.replace(/\.stl$/i, '') ?? 'mesh');
  onProgress({ step: 'analyse' });
  const b = bounds(shaded.positions), proposal = propose(b);
  return { glb, trianglesBefore, trianglesAfter: triangleCount(shaded), bounds: b, proposal, supports, volume: terrainVolume(b, proposal) };
}

/** A dropped GLB skips conversion; the preview still needs its count and extent, and terrain still needs its volume. */
export async function describeGlb(bytes: Uint8Array): Promise<{ triangles: number; bounds: Bounds }> {
  const { positions, triangles } = await readGlb(bytes);
  return { triangles, bounds: bounds(positions) };
}

export function convertInWorker(input: ConversionInput, onProgress: (p: Progress) => void = () => {}): Promise<ConversionResult> {
  return new Promise((resolve, reject) => {
    const worker = new Worker(new URL('./convert.worker.ts', import.meta.url), { type: 'module' });
    worker.onmessage = (e: MessageEvent<{ progress?: Progress; result?: ConversionResult; error?: string }>) => {
      if (e.data.progress) onProgress(e.data.progress);
      if (e.data.result) { resolve(e.data.result); worker.terminate(); }
      if (e.data.error) { reject(new Error(e.data.error)); worker.terminate(); }
    };
    worker.postMessage(input, input.files.map((f) => f.bytes));
  });
}
```

```ts
// web/src/lib/upload/upload.ts — the presigned path, in the management API's order. Nothing here converts; the plan carries finished bytes.
import { api } from '$lib/api/client';
import type { AssetDto, AssetKind, Base, ContentType, Orientation, TerrainVolume, Volume } from '$lib/api/types';
import { sha256Hex } from './sha256';

export type UploadStage = 'hash' | 'create' | 'put' | 'confirm' | 'volumes';
export interface UploadPlan { name: string; kind: AssetKind; contentType: ContentType; bytes: Uint8Array; scale: number; orientation: Orientation; modelledBase: Base | null; volume?: Volume }
export interface UploadOutcome { asset: AssetDto; triangles?: number; warning?: string; deduplicated: boolean; volumes?: TerrainVolume[] }

export class UploadError extends Error {
  constructor(public stage: UploadStage, public cause: unknown) { super(`Upload failed while ${stage === 'put' ? 'sending the bytes' : stage}: ${cause instanceof Error ? cause.message : String(cause)}`); }
}

export async function upload(plan: UploadPlan, onStage: (s: UploadStage) => void = () => {}): Promise<UploadOutcome> {
  let stage: UploadStage = 'hash';
  try {
    onStage(stage);
    const hash = await sha256Hex(plan.bytes);
    onStage((stage = 'create'));
    const created = await api.assets.create({ name: plan.name, kind: plan.kind, hash, byteSize: plan.bytes.byteLength, contentType: plan.contentType, scale: plan.scale, orientation: plan.orientation, modelledBase: plan.modelledBase });
    const deduplicated = !created.uploadUrl;
    if (created.uploadUrl) {
      onStage((stage = 'put'));
      const r = await fetch(created.uploadUrl, { method: 'PUT', headers: { 'content-type': plan.contentType }, body: plan.bytes as BodyInit });
      if (!r.ok) throw new Error(`${r.status} ${await r.text()}`);
    }
    onStage((stage = 'confirm'));
    const confirmed = await api.assets.confirm(created.asset.id);
    let volumes: TerrainVolume[] | undefined;
    if (plan.kind === 'terrain' && plan.volume) {
      onStage((stage = 'volumes'));
      volumes = await api.assets.putVolumes(created.asset.id, [plan.volume]);
    }
    return { asset: confirmed.asset, triangles: confirmed.triangles, warning: confirmed.warning, deduplicated, volumes };
  } catch (e) { throw e instanceof UploadError ? e : new UploadError(stage, e); }
}
```

```ts
// web/src/lib/upload/intake.ts
export type Intake<F extends { name: string } = File> =
  | { kind: 'stl'; files: F[] } | { kind: 'glb'; file: F } | { kind: 'image'; file: F; contentType: 'image/png' | 'image/jpeg' } | { kind: 'rejected'; reason: string };

export function classifyFiles<F extends { name: string }>(files: F[]): Intake<F> {
  const ext = (f: F) => f.name.toLowerCase().split('.').pop() ?? '';
  if (files.length === 0) return { kind: 'rejected', reason: 'Drop one or more .stl files, one .glb, or one .png/.jpg.' };
  if (files.every((f) => ext(f) === 'stl')) return { kind: 'stl', files };
  if (files.length === 1 && ext(files[0]!) === 'glb') return { kind: 'glb', file: files[0]! };
  if (files.length === 1 && ['png', 'jpg', 'jpeg'].includes(ext(files[0]!))) return { kind: 'image', file: files[0]!, contentType: ext(files[0]!) === 'png' ? 'image/png' : 'image/jpeg' };
  if (files.some((f) => ext(f) === 'gltf')) return { kind: 'rejected', reason: 'A .gltf with external buffers is several files; export a single .glb (GLB) instead.' };
  return { kind: 'rejected', reason: 'Mix not understood: drop STLs together, or one GLB, or one image.' };
}
```

```ts
// web/src/lib/library/folders.ts — folders are a client-side grouping over the whole library; nothing else reads them.
import type { AssetDto, AssetKind, Base, FolderDto, Guid } from '$lib/api/types';
export interface FolderNode { folder: FolderDto; children: FolderNode[] }

export function buildTree(folders: FolderDto[]): FolderNode[] {
  const byParent = new Map<Guid | undefined, FolderDto[]>();
  for (const f of folders) byParent.set(f.parentId, [...(byParent.get(f.parentId) ?? []), f]);
  const build = (parent: Guid | undefined): FolderNode[] =>
    (byParent.get(parent) ?? []).sort((a, b) => a.name.localeCompare(b.name)).map((f) => ({ folder: f, children: build(f.id) }));
  return build(undefined);
}
export function descendantIds(folders: FolderDto[], id: Guid): Set<Guid> {
  const out = new Set<Guid>([id]);
  let grew = true;
  while (grew) { grew = false; for (const f of folders) if (f.parentId && out.has(f.parentId) && !out.has(f.id)) { out.add(f.id); grew = true; } }
  return out;
}
const sameBase = (x: Base, y: Base) => x.shape === y.shape && Math.abs(x.a - y.a) < 0.005 && Math.abs(x.b - y.b) < 0.005;
/** A folder shows its own assets and its sub-folders'; an asset in no folder shows only under *All*. */
export function filterAssets(assets: AssetDto[], folders: FolderDto[], f: { folderId: Guid | null; kind?: AssetKind; base?: Base }): AssetDto[] {
  const subtree = f.folderId ? descendantIds(folders, f.folderId) : null;
  const inFolders = subtree ? new Set(folders.filter((x) => subtree.has(x.id)).flatMap((x) => x.assetIds)) : null;
  return assets.filter((a) => (!inFolders || inFolders.has(a.id)) && (!f.kind || a.kind === f.kind) && (!f.base || (a.modelledBase !== undefined && sameBase(a.modelledBase, f.base))));
}
```

```ts
// web/src/lib/library/volume-edit.ts
import type { Declaration, FootprintKind, Volume, VolumeKind } from '$lib/api/types';
import { formatDeclarations, parseDeclarations } from '$lib/units/volumes';

export interface VolumeDraft { kind: VolumeKind; footprintKind: FootprintKind; a: number; b: number; offsetX: number; offsetY: number; yawDegrees: number; bottom: number; top: number; declarations: Set<Declaration>; notes: string }

export const toDraft = (v: Volume): VolumeDraft => ({ kind: v.kind, footprintKind: v.footprint.kind, a: v.footprint.a, b: v.footprint.b, offsetX: v.offset.x, offsetY: v.offset.y, yawDegrees: v.yaw.degrees, bottom: v.bottom, top: v.top, declarations: parseDeclarations(v.declarations), notes: v.notes ?? '' });

export function fromDraft(d: VolumeDraft): Volume {
  const notes = d.notes.trim();
  return { kind: d.kind, footprint: { kind: d.footprintKind, a: d.a, b: d.footprintKind === 'circle' ? d.a : d.b }, offset: { x: d.offsetX, y: d.offsetY }, yaw: { degrees: d.yawDegrees }, bottom: d.bottom, top: d.top, declarations: formatDeclarations(d.declarations), ...(notes ? { notes } : {}) };
}

export function validate(d: VolumeDraft): string[] {
  const errors: string[] = [];
  if (!(d.top > d.bottom)) errors.push('top must be above bottom');
  if (!(d.a > 0) || (d.footprintKind === 'rect' && !(d.b > 0))) errors.push('dimensions must be positive');
  if (d.declarations.has('see_in_and_out') && !d.declarations.has('blocks_line_of_sight')) errors.push('see in and out needs blocks line of sight');
  return errors;
}

/** The top-down camera shows [minX, maxX] × [minY, maxY] across the viewport with +Y up the screen. */
export function screenToTable(px: number, py: number, viewport: { width: number; height: number }, e: { minX: number; maxX: number; minY: number; maxY: number }) {
  return { x: e.minX + (px / viewport.width) * (e.maxX - e.minX), y: e.maxY - (py / viewport.height) * (e.maxY - e.minY) };
}
```

```ts
// web/src/lib/armies/import.ts — the browser hands management a source; management fetches and parses the list.
import { api } from '$lib/api/client';
import { ApiError } from '$lib/api/http';
import type { Army } from '$lib/api/types';

const ID = /^[A-Za-z0-9_-]{4,64}$/;

/** A share link is passed through whole (management reads its id= and keeps the link as `source`); other URLs with an id= collapse to the id; a bare id passes. */
export function normaliseSource(text: string): string | null {
  const t = text.trim();
  if (!t) return null;
  if (/^https:\/\/army-forge\.onepagerules\.com\/share\?/.test(t) && /[?&]id=[A-Za-z0-9_-]+/.test(t)) return t;
  const m = /[?&]id=([A-Za-z0-9_-]+)/.exec(t);
  if (m) return m[1]!;
  return ID.test(t) ? t : null;
}

export function importErrorMessage(e: unknown): string {
  if (!(e instanceof ApiError)) return 'Something went wrong. Try again.';
  if (e.status === 502) return `Army Forge did not answer (${e.detail ?? e.title}). Check the link is a public share link and try again.`;
  return e.detail ?? e.title;
}

/** A changed list means a re-import: a new army from the same source, then the old one goes. Nothing is reconciled. */
export async function reimport(army: { id: string; source: string }): Promise<Army> {
  const fresh = await api.armies.import(army.source);
  await api.armies.delete(army.id);
  return fresh;
}
```

```ts
// web/src/lib/armies/patches.ts
import type { Base, Guid, ModelSlot, PatchArmyRequest, PropertyInstance } from '$lib/api/types';

const slot = (slotId: Guid, over: Partial<{ assetId: Guid | null; clearAsset: boolean; base: Base | null; height: number | null }>): PatchArmyRequest =>
  ({ slots: [{ slotId, assetId: null, clearAsset: false, base: null, height: null, ...over }] });

export const unitDefault = (unitId: Guid, assetId: Guid | null): PatchArmyRequest => ({ units: [{ unitId, assetId }] });
export const slotMesh = (slotId: Guid, assetId: Guid | null): PatchArmyRequest => slot(slotId, assetId ? { assetId } : { clearAsset: true });
export const slotBase = (slotId: Guid, base: Base): PatchArmyRequest => slot(slotId, { base });
export const slotHeight = (slotId: Guid, height: number): PatchArmyRequest => slot(slotId, { height });
export const rename = (name: string): PatchArmyRequest => ({ name });

const prop = (p: PropertyInstance) => (p.parameter === undefined ? p.name : `${p.name}(${p.parameter})`);
export function slotSummary(s: ModelSlot): string {
  const weapons = s.weapons.map((w) => `${w.name} (${[w.stats['Range'], w.stats['Attacks'] ? `A${w.stats['Attacks']}` : undefined, ...w.properties.map(prop)].filter(Boolean).join(', ')})`).join(', ');
  const props = s.properties.map(prop).join(', ');
  return [weapons, props].filter(Boolean).join(' · ');
}
```

## Questions answered from the documents, and what they settled

Six questions this plan first asked turned out to be answered already; each answer is now built into the tasks above.

- **The `Orientation` convention.** Fixed by the contracts plan: `Orientation(Pitch, Yaw, Roll)` in degrees, "raw mesh coordinates read as table coordinates, rotated Pitch about X, then Roll about Y, then Yaw about Z (right-handed, extrinsic), then scaled; a Y-up glTF stands at Pitch = 90 — the web app writes it, the client's `MeshLoader.Orient` applies it". `toWorld`, `eulerFor` and `propose` implement exactly that. Spec correction 4 mirrors it into geometry values; it does not decide it.
- **Baking scale and orientation into the GLB.** No. Mesh conversion → *What it writes*: "the converter proposes, the user confirms in the preview, and **the fields hold the confirmed value**", and "a GLB dropped straight in gets no proposal and the user sets both" — fields that were always identity would hold nothing to confirm and would make a dropped GLB behave differently from a converted one. The GLB keeps the file's units and axes; the asset row carries scale and orientation.
- **Centring the mesh.** Yes, and it is not a new decision: mesh conversion → *The flow* has the mesh **standing on a ring** of the modelled base, and the table domain model has the base as the hitbox the mesh only decorates. A mesh exported off-origin cannot stand on its base either in the preview or in play, so the footprint is centred on the origin with the lowest point at zero. Spec correction 3 records the step that follows from it.
- **`Tabletop-Client-Version` from the web app.** No. The management API spec puts the version check there "because the Godot client is a downloaded desktop application and a user can be months behind"; the SPA is fetched from the server on every load and cannot be behind. Management accepts a missing header (management plan), so no header is sent and `426` cannot reach this app.
- **Conversion in a Web Worker.** Yes, and it is the plan's to settle: mesh conversion leaves "which parser, simplifier and exporter" to implementation and asks only that the pipeline run headless. `convert()` is the pipeline and knows nothing of the DOM; `convertInWorker` is a wrapper so a two-million-triangle STL does not freeze the page. Recorded in Task 9.
- **Paging the library grid.** Load-all, 200 per request, with folders and the base filter client-side. The asset library names the problem — "a user with five hundred meshes finding one, together with the modelled base as a filter" — and folders are membership lists, so filtering needs the whole set. The keyset pager stays available if a library ever outgrows this; that is the note in Task 13, not a question.
