# Grimdark Future v3.6.0 — page 66

ROLLING FOR RANDOM EVENTS
When rolling for random events, roll two separate dice one at a
time, where the first one represents the first number, whilst the
second one represents the second number, and resolve that event.
Example: A player rolls two dice, with the first result being a 2 and the
second result being a 1. This would mean that event 21 is chosen.
ROLLING FOR RANDOM UNITS
If a random event calls for randomly selecting a unit from any
warband you must first randomly select a warband for the event,
and then randomly select a unit to be the target.
