# Grimdark Future v3.6.0 — page 51

MEAT GRINDER BATTLES
Meat Grinder battles are long battles where more and more units
are deployed as the game goes on, making for bloody battles with
lots of casualties.
There are two types of meat grinder battles you can play, either
with respawning units, or with unit recruitment.
RESPAWNING UNITS
Set up the mission normally, placing 5 objectives, and using the
standard deployment rules.
When a unit is destroyed, it is placed in reserves with X tokens,
where X is one for every full 5% of the total points of the army the
unit cost (rounding up).
Example: When playing a 2000pts game, destroyed units get 1 token
per full 100pts that they cost. This means that a 90pts unit would get
0 tokens, whilst a 250pts unit would get 2 tokens.
Players may also voluntarily destroy any of their units that have
half or less of their total size or Tough value (for single-model units)
left when they are activated.
At the beginning of each round, starting with the player that
activates next, players alternate in rolling one die for each unit in
reserves, trying to roll higher than the total number of tokens on
that unit. If successful, remove all tokens from the unit and deploy
it following the standard deployment rules. If failed, remove one
token from the unit instead.
When an enemy unit is destroyed, players score X VPs, where X is
that unit’s point value (rounding up), and at the end of the game
players get X/2 VPs (rounding up)for enemy units with half or less of
their total size or Tough value (for single-model units) on the table.
The game ends after 6 rounds, players get X VPs for each objective
they control, where X equals 20% of the total points of each army
(rounding up). The player with most VPs wins.
Example: When playing a 2000pts game, at the end of the game each
controlled objective is worth 400 VPs. During the game, destroying a
200pts unit scores 200 VPs, whilst a 200pts unit with half or less of its
total size scores 100 VPs at the end of the game.
UNIT RECRUITMENT
Set up the mission normally, placing 5 objectives, and using the
standard deployment rules.
Select a total game size, and players start the game with as many
points as 50% of total game size to recruit units (rounding up),
which are then deployed at the beginning of the game as usual.
At the end of each round, players get as many points as 15% of
total game size, plus as many points as X * 1% of total game size for
each objective they control (rounding up), where X is the current
round number.
At the beginning of each round, starting with the player that
activates next, players may alternate in spending their points to
recruit units and deploy them following the standard deployment
rules, however players may spend max. as many points as 30% of
total game size each round (rounding up). Recruited units can’t
seize or contest objectives on the round they deploy.
Example: For a 2000pts game, you start with 1000pts, get 300pts to
spend each round, score X*20pts per objective (where X is the current
round number), and can spend a max. of 600pts.
At the end of each round players get X VP for each objective marker
they control, where X is the current round number.
After 6 rounds have been played the game ends, and the player
that scored most VPs wins.
Underdog System (optional): Starting at the end of the third
round, at the end of each round, if one player has fewer VPs than
the other, then they count as the underdog for that round. Only the
underdog scores as many points as 15% of total game size at the
end of the round.
