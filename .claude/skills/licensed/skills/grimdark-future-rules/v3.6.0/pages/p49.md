# Grimdark Future v3.6.0 — page 49

PLAYING WITH POLITICAL INTRIGUE
Political Intrigue rules add a new strategic layer on top of the
regular game, giving players the ability to influence the game and
mess with each other’s plans.
Before the game begins, players have to pick if they’re going to play
using only directives, or if they will also use politicians.
DIRECTIVES
Twice per round, instead of activating one of their units, players
may may choose to use one directive that hasn’t been used yet this
round. Note that players may not use directives if they’ve run out of
units to activate.
• Influence: Pick one objective that is controlled by either
player, which becomes neutral again.
• Propaganda: Pick one enemy unit, which must take a
Morale Test. If failed, the unit is Shaken.
• Recruitment: Pick one friendly unit, which restores D3
models/wounds. Note that new models may only be
restored if they can be placed in coherency with non-
restored models.
• Industry: Pick one friendly unit, which may immediately
shoot at one enemy unit within 12”.
• Mobilization: Pick one friendly unit, which may
immediately move by up to 6” in any direction.
POLITICIANS
Before the game begins, pick one of the following playstyles, or roll
a D3 to randomly get one:
1. Open - Each player selects two politicians openly.
2. Open + Hidden - Each player selects one politician
openly, and one politician in secret.
3. Hidden - Each player selects two politicians in secret.
When a player uses a directive, they may declare that it is being
used by one of their politicians of that directive type that hasn’t
been used yet this round. Secret politicians are revealed when they
are used for the first time, but note that you may choose directives
without using any politician, so as to keep them secret.
• Warmonger (Influence/Propaganda): Once per game, when
using this directive, the target enemy unit takes D3 wounds, or
one enemy unit within 3” of the chosen objective takes D3
wounds.
• Ambassador (Influence/Recruitment): When using this
directive, the closest friendly unit to the target unit or
objective may move 3” directly towards it.
• Mastermind (Influence/Industry): When using this directive,
the target friendly unit gets +1 to hit rolls until the end of the
round, or friendly units get +1 to hit rolls when attacking
enemies within 3” of the chosen objective until the end of the
round.
• Deceiver (Influence/Mobilization): When using this directive,
the target friendly unit may ignore Difficult and Dangerous
terrain until the end of the round, or the area within 3” of the
chosen objective counts as Difficult and Dangerous terrain
until the end of the round.
• Negotiator (Propaganda/Recruitment): Once per game,
when using this directive, the target friendly unit may restore
D3 models/wounds, or the target enemy unit takes D3
wounds.
• Trader (Propaganda/Industry): When using this directive, the
target friendly unit gets AP(+1) until the end of the round, or
friendly units get AP(+1) when attacking the target enemy unit
once (next time the effect would apply).
• Manipulator (Propaganda/Mobilization): Once per game,
when using this directive, you may move the target unit by up
to 6” in any direction.
• Warden (Recruitment/Industry): When using this directive,
enemy units get AP(-1), to a min. of AP(0), when attacking the
target friendly unit until the end of the round.
• Visionary (Recruitment/Mobilization): When using this
directive, the target friendly unit stops being Shaken.
• Escalator (Industry/Mobilization): Once per game, when
using this directive, the target friendly unit may move twice or
shoot twice (even at different targets).
